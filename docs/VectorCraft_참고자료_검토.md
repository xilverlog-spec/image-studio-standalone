# VectorCraft(참고자료/vectorcraft-main.zip) 검토 — 2026-10-20

## 무엇인가
- **VectorCraft**: ArtCraft 팀의 오픈소스 **벡터 일러스트 앱**(일러스트레이터 대응). **순수 Rust**, 데스크톱 + WebAssembly 웹판. 라이선스 **MIT 또는 Apache-2.0**(NOTICE 에 서드파티·글꼴·아이콘 라이선스 목록). `.vectorcraft`(JSON) + SVG·PDF·PNG 등 입출력, MCP 서버(에이전트가 그림을 그리는 명령 채널).
- 상태: 알파(자체 평가 핵심 기능 약 88%·실무 준비도 약 65%). 우리 앱(JS/React)에 **그대로 넣을 수는 없다**(Rust 소스만 들어 있고, 이 PC 에는 Rust 도구가 없어 웹판을 직접 빌드할 수도 없다). 쓸 수 있는 것은 **기능 아이디어·동작 방식과(필요하면) 알고리즘을 JS 로 다시 구현**하는 것.
- 압축 파일은 프로젝트와 분리한 임시 폴더에 풀어 읽었고(48MB, 1,975개 파일), 그 안의 AGENTS.md·CLAUDE.md 는 그 프로젝트 기여자용 지침이라 따르지 않았다.

## 우리 편집기에 이미 있는 것 / 없는 것(현재 코드 기준)
- 있음: 정렬·간격 균등, 복사·붙여넣기·복제, 자석(스냅)·안내선, 회전, 전체 크기 조절, 글자 정렬·자간·행간, 번호 마커·리더선·아이콘·표·방위표·축척 막대, 넣은 이미지의 앞/뒤.
- **없음**: 치수선, 개체 목록(레이어)과 일반 도형의 앞/뒤 순서·잠금·숨김, 그룹 묶기, 해칭·점 같은 무늬 채움, 도형 합치기/빼기, 배열 복사, 손으로 그린 선을 도형으로 정리, 모서리 둥글기 조절, 도형 모양으로 이미지 자르기.

## VectorCraft 에서 볼 만한 기능(우리 용도 기준, 우선순위 제안)
| 순위 | 기능 | VectorCraft 의 방식(docs 에서 확인) | 우리에게 | 비고 |
|---:|---|---|---|---|
| 1 | **치수선**(Dimension) | 선형·각도·반지름, 단위(mm·cm·m·ft…)·소수 자리·**축척 1:N**·글자 위치(선 바깥/선과 도형 사이)·정렬, 그림이 움직이면 같이 따라가는 연결 | 배치도·매스 도식에 거리·면적 표기, 이미 있는 축척 막대와 연결 | `docs/dimensions.md`. JS 로 새로 만들면 됨(기하는 단순) |
| 2 | **개체 목록(레이어) 패널** | 모든 개체가 한 줄씩, 순서·숨김·잠금·이름, 그룹 | 겹친 도형이 많은 결과에서 고르기·순서 바꾸기·숨기기 | 지금은 클릭으로만 고름. 효과 큼 |
| 3 | **무늬 채움**(patterns/swatches) | 해칭·점·격자 무늬 | 단면 해칭·포장 점·녹지 표현 | SVG `<pattern>` 으로 구현 가능 |
| 4 | **배열 복사(Repeat)** | 선형·방사·격자로 **살아 있는** 반복(원본을 고치면 모두 바뀜) | 주차 칸·창·기둥·세대 반복 | 처음엔 '배열 복사'(고정 복사)부터 |
| 5 | **Pathfinder(도형 합치기·빼기·교차)** | 정확한 곡선 불리언(`crates/pathops`, boolean.rs 756줄·offset.rs) | 매스 합치기·L자·건축선 후퇴(오프셋) | JS 에는 검증된 폴리곤 라이브러리(내려받기 허락 필요)를 쓰는 편이 안전 |
| 6 | **글자 상자(Area type)·경로 위 글자** | 상자 폭에서 자동 줄바꿈, 열·여백, 경로를 따라 흐르는 글자 | 설명 문단, 곡선 화살표 위 라벨 | 방금 넣은 정렬·자간·행간과 이어짐 |
| 7 | **Shaper(스케치→도형)** | 거칠게 그린 사각·원·삼각·선을 깨끗한 도형으로 | 손스케치 탭에 직접 그리기 | 간단한 인식(꼭짓점 수·종횡비)으로 시작 가능 |
| 8 | **Clipping mask·모서리 둥글기 위젯** | 도형 모양으로 사진 자르기, 모서리별 반지름 | 사진을 원·둥근 사각으로 | 우리 자르기는 사각뿐 |
| 9 | **타일 인쇄**(print-tiling) | 큰 도면을 A4/A3 여러 장으로 나눠 번호·겹침(overlap) 인쇄 | A0/A1 보드를 작은 프린터로 시안 출력 | 페이지 모드와 잘 맞음. 우선순위 낮음 |
| 10 | **PDF 내보내기** | 벡터 PDF | SVG·PNG 외에 벡터 PDF | 브라우저 인쇄 → PDF 로도 가능 |
