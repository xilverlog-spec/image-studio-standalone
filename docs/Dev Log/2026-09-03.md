# 2026-09-03

## Done
- 보관함(갤러리)에 "폴더별 정리" 기능을 새로 구현했다. 이미지 한 장은 폴더 하나에만 속하도록 설계했고, 폴더 생성/이름 변경/삭제, 이미지를 폴더에 넣고 빼는 기능을 백엔드(API + DB)와 프론트엔드(칩 목록, 카드별 폴더 담기 팝오버)에 모두 연결했다.
- 이미지 블렌딩 결과를 보관함 라이트박스에서 "전/후" 비교 슬라이더로 볼 수 있게 만들었고, 처음엔 브라우저 메모리에만 있던 원본(블렌딩 전) 이미지를 서버 파일로 같이 저장해 새로고침/재시작 후에도 비교가 유지되도록 개선했다.
- 블렌딩 기능에 텍스트 프롬프트 추가 입력과, 프로 모드에서 "기존 이미지 감도"를 수동으로 지정할 수 있는 옵션을 추가했다.
- 서버(Vite/백엔드/ComfyUI) 상태와 접속 링크를 읽기 전용으로 점검하는 server-status 스킬을 새로 만들었다.

## Problem
- 갤러리 카드 전체에 모서리를 둥글게 하려고 overflow:hidden을 걸었더니, 카드 밖으로 나가야 하는 폴더 담기 팝오버까지 함께 잘려서 안 보이는 문제가 있었다. 정사각형 썸네일 영역만 따로 잘라내고 팝오버는 카드 레벨에 남겨 해결했다.
- 폴더 담기 팝오버에서 같은 폴더를 다시 누르면 빠지지 않고 계속 선택된 상태였는데, 같은 폴더를 다시 누르면 해제되도록(토글) 고치고 선택된 폴더에 체크 표시를 추가했다.

## Decision
- 갤러리 정리 기능은 검토 문서(FAVORITES_FOLDER_FEATURE.md)에서 제안했던 폴더-이미지 다대다 매핑 테이블 대신, "이미지 1장 = 폴더 1개"로 단순화한 단일 컬럼(`folder_id`) 설계로 구현하기로 결정했다. 폴더를 지워도 안의 이미지는 삭제되지 않고 "폴더 없음" 상태로 돌아간다.

## 요약
- 사진 보관함에 폴더를 새로 만들어서 원하는 대로 사진을 분류해 담을 수 있는 기능을 추가했다. 사진 한 장은 폴더 하나에만 넣을 수 있고, 폴더를 지워도 사진은 사라지지 않는다.
- 여러 사진을 합성(블렌딩)한 결과를 볼 때, 화면에서 슬라이더를 밀어서 "합성 전"과 "합성 후" 사진을 바로 비교해볼 수 있게 했다. 이제는 페이지를 새로고침해도 비교 화면이 그대로 유지된다.
- 합성할 때 글로 원하는 느낌을 추가로 적을 수 있게 하고, 원본 사진을 얼마나 반영할지도 더 세밀하게 조절할 수 있게 했다.
- 폴더 담기 버튼을 눌렀을 때 목록이 화면 밖으로 잘려 보이던 오류와, 같은 폴더를 다시 눌러도 선택이 풀리지 않던 오류를 고쳤다.
- 서버가 잘 켜져 있는지, 외부 접속 링크가 살아있는지 빠르게 확인할 수 있는 점검 기능도 마련했다.
