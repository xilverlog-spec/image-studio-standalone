- 헤더 브랜딩 문구를 "상지건축 AI Image Studio"에서 "상지건축 DX설계본부 AX LAB"으로 변경 (`index.html`, `src/App.jsx`).
- 매일 자동 생성되는 개발일지 스크립트(`Generate-DevLog.ps1`)에 UTF-8 콘솔 인코딩을 강제 설정해 한글이 깨져서(mojibake) 저장되던 문제를 고치고, 이미 깨져 있던 9/1~9/3 Dev Log 및 `Architecture.md`/`Decisions.md` 문서를 정상 한글로 복구.

## Problem
- 개발일지 자동 생성 스크립트가 Windows 작업 스케줄러의 시스템 로캘(CP949)로 실행되면서 한글 텍스트가 깨져 저장되던 문제를 발견하고 수정.
- 설치 프로그램(`설치하기.bat`)을 NAS 공유폴더(UNC 경로)에서 직접 더블클릭하면 cmd.exe가 UNC 경로를 현재 디렉터리로 잡지 못해 "내부 또는 외부 명령이 아닙니다" 오류가 나는 문제를 발견 — 실행 시 설치 폴더를 로컬 임시폴더로 복사한 뒤 그곳에서 재실행하도록 수정. 관리자 권한 승격 과정에서도 공백/한글이 섞인 경로 때문에 따옴표 이스케이핑이 꼬이는 문제가 있어, 별도 `Elevate.ps1` 파일로 분리해 해결.

## Decision
- 사내 100명 배포 시 각 PC에 Node.js 설치를 요구하지 않기 위해, 프론트엔드를 미리 빌드(`dist/`)해 백엔드(FastAPI) 프로세스 하나가 직접 서빙하는 방식으로 통합하기로 결정 — 설치 요구사항을 Python 하나로 최소화하기 위함.

## 요약
- 회사 내 100명이 쓸 수 있도록, 다른 컴퓨터에서 복잡한 설치 없이 아이콘 하나로 프로그램을 자동으로 설치해주는 기능을 새로 만들었다.
- 프로그램을 설치할 때 인터넷에서 새로 뭔가를 받지 않고 회사 공유폴더에서 필요한 파일을 그대로 복사해오도록 만들어서 설치가 빠르고 간단해졌다.
- 화면(웹페이지)과 뒤에서 그림을 그려주는 부분을 하나로 합쳐서, 이제 컴퓨터에 별도 프로그램을 더 깔지 않아도 실행되게 만들었다.
- 공유폴더에서 설치 프로그램을 바로 실행하면 오류가 나던 문제와, 매일 자동으로 만들어지던 작업 기록이 한글이 깨져서 저장되던 문제를 둘 다 찾아서 고쳤다.
- 화면 위쪽에 표시되는 프로그램 이름도 "상지건축 DX설계본부 AX LAB"으로 바꿨다.
