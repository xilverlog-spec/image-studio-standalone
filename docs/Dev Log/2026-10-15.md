## 1. 저장된 읽기 결과 혼선 수정 (사용자 보고: 발코니 그림을 돌렸더니 이전 저장값이 불러와지고 다시 읽기를 못 누름)
- 재현: 같은 그림은 읽기 결과를 저장해 재사용(무료 한도 절약)하는데, 이때 알림 토스트만 뜨고 화면에는 표시가 없었고 '다시 읽기'는 왼쪽 패널 안에만 있어 눈에 띄지 않았다. 읽는 동안(10~40초)에는 컨트롤 9개가 잠겨 선택되지 않는다.
- 확인된 구조 문제 2가지: ① 이전 빌드(보정 알고리즘이 달랐던 때)에 저장된 낡은 읽기 결과가 새 빌드에서도 그대로 재사용됨 ② 그림·설명 식별 해시가 글자를 5개마다 하나만 봐서 서로 다른 그림·설명이 같은 저장값으로 잡힐 수 있음.
- 수정(ConceptDiagram.jsx): 저장 공간 버전을 v2 로 올려 이전 빌드 저장분 무효화, 해시를 글자 전체 기준(FNV+djb2)으로, 저장된 결과를 쓸 때 읽기 패널에 '저장된 읽기 결과입니다' 안내와 눈에 띄는 **새로 읽기** 버튼 표시(읽는 동안만 잠김).
- 시험(임시 시험 페이지, 실제 Gemini): 처음 읽기(AI 호출) → 같은 그림 다시 만들기 시 저장 결과 사용+안내+새로 읽기 버튼 활성 → 새로 읽기 누르면 AI 3회+정리 호출로 새로 읽고 안내 사라짐. 확인 못 한 것: 사용자가 본 발코니 그림 자체(파일이 없음), 재현 조건은 추정.

## 2. 이미지 → SVG 변환이 짜글짜글하게 깨지는 문제 (사용자 보고: 연한 회색 면·흐린 그라데이션 화살표·굵은 검정 선 그림)
- 재현(보내준 결과 그림을 원본 대용으로, 가우시안으로 계단을 풀어 사용): '깔끔하게' 모드는 3배 확대+중간값 필터 5+거친 색 단계(5)로 흰 바탕에 가까운 연한 면과 벽이 배경에 먹혀 거의 사라지고, '원본에 가깝게' 모드는 색을 층층이 쪼개 계단 띠·거친 가장자리가 생김. vtracer 는 색이 연속으로 변하는 그림에 약함.
- 구현(backend/services/vector_smooth.py, `/image/vectorize` mode=smooth, 새 기본): ① Lab 색공간 k-평균으로 14개 대표색(흰 바탕 비중을 줄여 연한 색도 살림) ② 대표색마다 영역 경계를 가우시안으로 부드럽게(가는 어두운 선은 가중치로 보존) ③ 평면 색 그림을 vtracer 에 넘김. 화면(DrawioEditor): '부드럽게(권장)' 추가 및 기본 선택, 기존 두 모드 유지.
- 시험: 같은 그림에서 벽·화살표·그라데이션이 모두 남고 가장자리가 깨끗(긴 변 2400px, 3.4초). 평평한 선화(full6.png, 6칸 매스 다이어그램)에서도 '깔끔하게'와 같거나 더 또렷. 색 연속성 점수로 자동 선택하는 안은 이 그림(0.17)과 평평한 그림(0.05~0.14)이 겹쳐 버림 → 항상 부드럽게를 기본으로.
- 주의: 백엔드를 재시작해야 반영됨(사용자가 시험 중이라 아직 재시작하지 않음). 실제 원본 파일은 없어서 보내준 결과 그림으로 재현함 → 원본으로 최종 확인 필요.
