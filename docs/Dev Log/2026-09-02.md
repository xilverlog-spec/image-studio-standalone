## Problem
- 기존 클라우드 기반 자동 백업 루틴이 이 PC의 로컬 파일 변경을 인식하지 못해 항상 "변경사항 없음"으로 끝나고, 실제로는 아무것도 백업되지 않고 있던 문제를 발견.
- 최신 ComfyUI에서 모델 목록 응답 스키마가 바뀌면서, 실제 모델 이름 목록이 아니라 타입 표시 문자열("COMBO") 자체를 목록으로 착각해 업스케일 기능이 항상 실패하던 버그를 확인 및 수정.
- 프롬프트 확장, Sharpness/ADM Guidance 등 여러 기능이 실제로는 아무 효과가 없는 placeholder 상태로 남아 있던 것을 확인하고, 실제 커스텀 노드와 연결해 동작하도록 고침.

## Decision
- 클라우드 루틴 대신 로컬 Windows 작업 스케줄러 기반 백업/개발일지 생성 체계로 전환하기로 결정 — 클라우드 환경은 로컬 파일에 접근할 수 없어 실질적인 백업 효과가 없었기 때문.
- 이미지 블렌딩 기능은 Fooocus 원본처럼 "기본 이미지 vs 참조 이미지"라는 고정 역할 구분 대신, 슬롯마다 타입(구조 유지용/스타일 참고용)과 설정을 독립적으로 갖는 구조로 재설계하기로 결정 — 실제 Fooocus UI에도 고정 역할 구분이 없고 슬롯이 스스로 역할을 정하는 방식이기 때문.

## 요약
오늘은 사진을 합성하는 기능을 크게 손봐서, 이제 최대 4장까지 참고 이미지를 넣고 각각 다른 방식(모양을 그대로 따라가게 하거나, 분위기만 참고하게 하거나)으로 섞을 수 있게 됐다. 화질 설정 중 그동안 겉으로만 있고 실제로는 적용되지 않던 항목들을 실제로 작동하게 고쳤고, 최근 프로그램 업데이트 때문에 항상 실패하던 이미지 확대 기능의 버그도 찾아서 고쳤다. 그동안 작업 내용을 매시간 자동으로 저장해주던 기능이 사실은 전혀 작동하지 않고 있었다는 걸 발견해서, 이 컴퓨터 자체의 예약 작업 기능으로 새로 만들어 이제는 실제로 매시간 백업되고, 매일 저녁에는 그날 한 일을 자동으로 정리해서 기록해준다. 사내 다른 사이트와 디자인 느낌을 맞추기 위한 참고 문서와 로고도 함께 추가했다.
