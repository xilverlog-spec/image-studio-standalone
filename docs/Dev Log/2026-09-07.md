## Problem
- 이미지 생성 시 스텝당 수 분씩 걸리는 심각한 속도 저하가 발생했고, 원인은 ComfyUI 프로세스가 중복 실행되어 GPU VRAM을 나눠 점유하고 있었기 때문으로 확인됨. 중복 프로세스를 강제 종료해 해결.

## 요약
- 이미지를 생성할 때 한 단계마다 몇 분씩 걸리던 심각한 속도 저하 문제를 고쳤다. 원인은 그림 그려주는 프로그램이 실수로 두 개 동시에 켜져 있어서 그래픽카드 메모리를 나눠 쓰고 있었던 것이었다. 중복으로 실행 중이던 프로그램을 찾아서 종료하자 다시 정상 속도로 돌아왔다. 이 문제를 찾고 고치는 데 썼던 점검 방법들을 다음에도 빠르게 다시 쓸 수 있도록 저장해뒀다.
