# 손스케치 → 다이어그램 직접 테스트 안내

직접 써 보시고 결과를 알려 주시면 정확도를 더 올리는 데 가장 큰 도움이 됩니다. **잘 안 된 그림이 가장 귀한 자료**입니다.

## 왼쪽 패널 탭 (2026-10-20, R9 + 후속 정리)
- 왼쪽 맨 위에 **① 만들기 · ② 페이지** 탭이 있고, **카드 보드·개요표 결과가 있을 때만 ③ 구성 수정**이 나타납니다. 한 번에 한 탭만 보이며 기본 상태에서 패널이 **한 화면 안**에 들어옵니다(이전에는 화면의 약 2.4배).
  - **① 만들기**: 1. 설명 → 2. 소재 이미지 / 3. 스타일 참고(둘이 나란히) → 종류(+시작 틀·예시 버튼) → **✨ 다이어그램 만들기**. 외부 전송 경고는 만들기 단추 위에 한 줄, **AI 모델은 "고급 설정"** 에 접었습니다.
  - **② 페이지**: 기본으로는 **켜기 · 용지 크기(↔ 가로·세로) · 칸 배치(작은 그림 19개 중에서 눌러 고름)** 만 보입니다. 꺼져 있으면 켜기 줄만 보입니다. **칸은 오른쪽 미리보기에서 직접 눌러 고릅니다**(칸 단추 줄은 없앴습니다). 그 외는 접혀 있습니다 — **"선택한 칸 설정 — 칸 N · 크기"**(칸 mm·라벨·설명·나누기·삭제·비우기·다른 칸으로 옮기기·예시 그림) / **"세부 설정"**(칸 간격·용도·직접 격자, 그 안에 바깥 여백·테두리 / 글자 크기·글꼴·맞춤·해상도 / 머리·꼬리(제목·구분 라벨·오른쪽 위 라벨·프로젝트명·쪽번호·칸 라벨 접두어·강조색)). 가로·세로 mm 입력은 용지를 "직접 입력"으로 고를 때만 나옵니다. 긴 설명은 마우스를 올리면 나오는 설명(툴팁)으로만 있습니다.
  - **③ 구성 수정**(카드 보드·개요표일 때만): **글자 입력칸이 없습니다.** 글자는 **오른쪽 그림에서 더블클릭**해서 바로 고치고(폼에도 안내가 있습니다), 여기서는 **구조**만 다룹니다 — 카드 보드: 띠·카드·항목 더하기/지우기/순서, 아이콘 고르기, 이미지 넣기·맞춤, 머리색·열 수, 카드마다 **부제 있음/없음 · 그림 칸 0~3 · 불릿 0~2 · 작은 이름 있음/없음**(새로 생긴 글자는 "내용을 입력하세요" 같은 기본 문구가 들어가 그림에서 고칩니다), 핵심 가치 번호는 항목을 더하고 지울 때 **자동으로 01, 02…** 로 다시 매겨집니다. 개요표 칸: 행(위·아래·삭제·추가)·열 수·스타일·엑셀 붙여넣기(새 행·열에는 "항목/내용"이 들어가 있어 그림에서 고칠 수 있고, 빈 칸이 생기면 "빈 칸을 – 로 채우기" 단추가 나옵니다).
  - **일반 "글자 수정" 목록(배치 개념도·매스·버블도·조닝도)은 없앴습니다.** 그림 위 글자를 더블클릭하면 바로 고칩니다.
- **카드 보드·개요표를 ① 에서 만들면 자동으로 ③ 으로 넘어갑니다.** 탭 이름 옆 **초록 점**은 "② 페이지 모드가 켜져 있음"입니다. 마지막에 본 탭은 기억합니다. (이전 문서의 "왼쪽 아래 ○○ 수정"은 ③ 구성 수정, "📐 상자"는 ② 페이지입니다.)

## 만들 수 있는 것 · 없는 것 (종류 안내, 2026-10-20)
- 왼쪽 **종류** 선택 아래의 **"📘 만들 수 있는 것 · 없는 것 (종류 안내)"** 를 열면 종류마다 **예시 그림 + 만들 수 있는 것 / 만들 수 없는 것 / 넣어야 하는 입력**이 카드로 나옵니다. 카드의 **"자세히"** 로 펼치고, 설명만으로 만드는 종류는 **"이 종류로"** 로 바로 고릅니다. 종류를 고르면 선택 칸 바로 아래에도 짧은 안내가 나옵니다.
  - **설명만으로 만들기(6)**: 배치 개념도 · 매스 과정도 · 프로그램 버블도 · 층별 조닝도 · 카드 보드 · 개요표
  - **이미지를 올려서 만들기(6, AI가 자동 판단)**: 도면 위 표시 · 평면 다이어그램 · 건물 형태 읽기 · 손스케치 정리 · 자유 해석 · 분석 축측도
  - (2026-10-20 사용자 의견으로 **"지원하지 않는 것" 묶음은 목록에서 뺐습니다**. 지원하지 않는 설명을 쓰면 만들기 전에 알리는 아래 "범위 밖 안내"는 그대로입니다.)
- **범위 밖 안내**: 종류를 "자동"으로 두고 설명에 "개요표를 만들어줘", "조직도 그려줘", "조감도를 그려줘", "평면도를 작성해줘", "로고 만들어줘" 같은 **지원하지 않는 것**을 적고 만들기를 누르면, AI를 부르기 전에 노란 안내 상자가 나옵니다. **가장 가까운 종류로 만들기 / 그대로 진행 / 설명 고치기** 중에서 고릅니다(설명을 고치면 안내가 닫힙니다). 종류를 직접 골랐을 때는 묻지 않습니다. 걸러내는 말은 일부러 구체적인 낱말만 써서 오탐이 적고, 걸려도 "그대로 진행"을 누르면 됩니다.
- **이미지가 '그 외'로 판단되면**(표·조직도·문서 스캔 등) 읽기 전에 멈추고 **자유 해석 / 도면 위 표시 / 손스케치** 중 가까운 방식을 고르게 합니다. 고르면 그 종류로 직접 지정되어 바로 이어서 읽습니다.

## 이미지 종류는 고르지 않아도 됩니다 (자동 판단)
- 이미지를 올리고 **미리 읽어서 확인하기**(또는 **다이어그램 만들기**)를 누르면 AI가 한 번 보고(무료 1회, 같은 그림은 저장) **손스케치 / 입체 그림 / 건물 사진 / 평면도 / 배치도**를 알아서 판단해 알맞은 방식으로 읽습니다. 판단 결과는 "🤖 자동 판단: …" 줄과 알림으로 알려 줍니다.
- 평면도는 **참고 이미지를 넣었거나 설명에 바람·통풍·일조·채광·남향·조망 같은 말이 있으면 분석 축측도**, 없으면 기존 평면 다이어그램으로 갑니다. 벽을 뽑지 못하면(평면도가 아니면) 알려 주고 평면 다이어그램으로 대신 읽습니다.
- 잘못 판단했으면 **"이미지 종류 직접 지정"**(접혀 있음)에서 직접 고를 수 있습니다.

## 그림 위에 동선·구역·방향·색을 얹을 때 (AI 이미지 편집, 무료, 약 2~7분)
- **평면도**는 설명에 **동선 / 조닝 / 부서별 / 구역별**이 있으면, **건물 사진·렌더·SketchUp 캡처·배치도·그 밖의 그림**은 **동선 / 접근 / 진입 / 출입 / 시선 / 일조 / 채광 / 조망 / 바람 / 통풍 / 구역 / 조닝 / 기능별 / 용도별 / 부서별 / 색으로 / 화살표** 같은 말이 있으면 자동으로 **"도면 위에 표시"** 방식으로 갑니다. 예) `차량 동선과 보행 동선을 구분해서 표시해줘`, `건물을 기능별(공용, 업무, 코어)로 색을 나눠 구분해줘`, `일조 방향과 시선 방향을 화살표로 표시해줘`
- 입체 스케치·수채 그림은 **동선·구역·기능별** 같은 분명한 말일 때만 이 방식으로 갑니다(바람·통풍·화살표는 지금처럼 자유 해석). **손스케치는 항상 손스케치 읽기**입니다. **스타일 참고 이미지를 넣으면** 이 방식은 참고 이미지를 쓰지 못하므로 쓰이지 않습니다.
- 서버가 (1) 무료 Gemini로 그림을 보고 AI 편집용 지시문을 쓰고 → (2) 이 PC의 AI(Qwen-Image 2.1)가 그림 위에 색과 화살표를 그리고 → (3) **평면도 같은 선 도면은 원본 위에 색과 화살표만 얹어서** 선·글자·치수를 원본 그대로 남기고(사진·3D 뷰는 AI가 장면을 다시 그린 결과를 씁니다) → (4) 결과에 실제로 나온 색으로 범례를 만들고, **Gemini가 완성된 그림을 다시 보고 범례의 뜻을 확인**합니다. 제목과 범례(■ 구역, ━ 동선)는 편집 가능한 글자입니다.
- **2~7분 걸립니다**(그림 크기에 따라, 처음 한 번은 AI 서버를 켜느라 1~2분 더). 진행 막대에 단계와 경과 시간이 나옵니다. 끝날 때까지 이 화면을 닫지 마세요. 그 사이 다른 그림 변환·AI 편집은 줄을 서서 기다립니다.
- **같은 요청도 매번 다르게 나옵니다.** 마음에 안 들면 다시 만들어 보세요. 시험 결과: 부서·매스·동선처럼 **큰 덩어리**는 잘 되지만, 작은 방이 많은 평면에서 **방마다 정확한 분류**(공용/사적 등)는 틀리는 방이 있습니다. 정확해야 하면 직접 확인하세요.
- **동선·일조·시선은 AI가 그럴듯하게 그린 것이지 계산이 아닙니다.** 일조 분석 결과물로 쓰지 마세요.
- 사진·3D 뷰는 장면이 다시 그려져 간판 글자 같은 세부가 조금 달라질 수 있습니다.
- **결과의 화살표·구역 색도 고칠 수 있습니다**: 서버가 결과를 (바탕 + 화살표 + 구역 색)으로 나눠 줍니다. **화살표는 클릭**하면 끝점·주황 점(굽음·꺾임)을 끌어 옮기고, 오른쪽에서 **색·굵기·선 종류(실선·파선·점선…)·화살촉·부드러운 곡선/꺾은선·점 추가/빼기**를 바꿉니다. **구역 색**은 오른쪽 "구역 색 (칠한 층)" 상자에서 층마다 **색·농도·이름·숨김**을 바꾸면 그 구역만 다시 칠해지고 선·글자는 그대로이며, 범례의 ■ 글자도 함께 바뀝니다. 자동으로 뽑는 것이라 완벽하지 않습니다(겹친 화살표 분리, 점선 종류, 화살촉 유무가 틀릴 수 있으니 확인해서 고치세요). 못 나누면 예전처럼 그림 한 장으로 나옵니다(이때는 색·위치를 고칠 수 없음).
- 다른 방식(평면 다이어그램·건물 형태 읽기 등 몇 초짜리)을 원하면 "이미지 종류 직접 지정"에서 고르세요. 매스 과정도처럼 말하면(동선·구역 말이 없으면) 건물 사진은 지금처럼 건물 형태 읽기로 갑니다.
- Gemini가 혼잡해서 지시문을 못 쓰면 일반 지시문으로 그리고 화면이 알려 줍니다(방 색칠이 덜 정확해질 수 있으니 잠시 뒤 다시 만드세요).
- 서버 PC에 Qwen 이미지 편집 환경(`C:\ComfyUI_v041`)이 없으면 이 방식은 쓰이지 않고 기존 방식으로 대신 만듭니다. 라이선스(Qwen Research License)가 비상업용이라 회사 업무에 계속 쓰기 전에 확인이 필요합니다.

## 시작하기
1. 사내 주소(백엔드, 5000번 포트)로 접속하고 **Ctrl+F5**로 새로고침합니다.
2. **다이어그램 탭 → 2. 소재 이미지**에 손스케치 사진을 올립니다.
3. 이미지 종류에서 **손스케치(펜으로 그린 개념 스케치)** 를 고릅니다.
4. **1. 설명**에 개념을 한 줄 적습니다. 예) `판상형 맞통풍 구조` — 도형 이름과 바람 방향, 제목을 이 문장대로 붙입니다.
5. **미리 읽어서 확인하기**를 누르면 읽은 모습을 먼저 볼 수 있고, **다이어그램 만들기**를 누르면 이름·제목까지 붙여 완성합니다.
6. 결과 화면에서 도형·화살표·선을 **끌어서 고치고** **SVG 저장**으로 내려받습니다.

## 입체·수채 그림은 자유 해석으로 읽습니다
- 평면 도면이 아니라고 판단되면 `입체·채색 그림이라 자유 해석으로 읽었습니다`라고 알리고, 고정 요소(회색)·움직이거나 강조된 요소(노랑)·회전/이동/흐름 화살표로 단순하게 다시 그립니다. **1번 설명이 읽을 때 쓰이므로** "가변형 공간이 많다는 다이어그램"처럼 의도를 적어 주세요(설명을 바꾸면 새로 읽습니다).
- 평면 스케치인데 잘못 판단됐으면 읽은 결과 아래 **평면 스케치로 다시 읽기** 버튼을 누르세요. 이미지 종류에서 **자유 해석**을 직접 고를 수도 있습니다.
- 사진(건물 외관)이나 배치도는 이 모드의 대상이 아닙니다(기존 '건물 형태'·'배치도' 읽기를 쓰세요).

## 그림 위 글자를 바로 고치기 (클릭 편집)
- **다이어그램을 만든 뒤 그림 속 글자를 그 자리에서 바로 고칠 수 있습니다.** 입력칸이 글자 위에 겹쳐 열리고, **Enter로 확정 · Esc로 취소**, 다른 곳을 누르면 확정됩니다. 왼쪽 "글자 수정" 목록과 같은 값이라 한쪽에서 고치면 다른 쪽에도 반영됩니다.
- **손스케치류 결과**(손스케치·자유 해석·분석 축측도·AI 이미지 편집): 글자를 **더블클릭**합니다(단일 클릭은 요소를 고르거나 옮기는 데 쓰임). 고칠 수 있는 글자: 제목·부제, 도형 이름·설명, 화살표 라벨, 메모 글자, 오른쪽 문구 블록(제목·부제), 핵심 메시지, 범례 글자. **메모를 골라 놓고 Enter 또는 F2**를 눌러도 열립니다.
- **그 밖의 결과**(배치 개념도·평면 다이어그램·매스 과정도·층별 조닝도·프로그램 버블도): 그림 속 글자를 **더블클릭**하면 열립니다(단일 클릭은 도형을 고르는 데 쓰임). **고칠 수 있는 글자는 마우스를 올리면 글자 커서가 됩니다.** 자동으로 만들어진 글자(범례의 자동 문구 등)를 더블클릭하면 "여기서 바로 고칠 수 없습니다" 안내가 나옵니다.
- **되돌리기**: 손스케치류는 편집기의 Ctrl+Z / Ctrl+Y, 그 밖의 결과는 **글자·도형을 고친 것을 Ctrl+Z / Ctrl+Y**로 되돌리고 다시 합니다(같은 결과 안에서, 최대 50단계). 입력칸에 글자를 쓰는 중의 Ctrl+Z는 입력칸 자체 동작입니다.
- **페이지 모드**에서도 같습니다: 오른쪽 위에 **고른 칸의 편집기**가 항상 보이고, 그 아래에 **📄 페이지 배치**(칸 크기 조절)가 이어집니다. 따로 "편집 화면"으로 들어갈 필요 없이 바로 고치고, 고친 모양은 아래 페이지 미리보기에 곧바로 반영됩니다. 다른 칸을 누르면 위 편집기가 그 칸의 그림으로 바뀝니다(칸을 더블클릭하면 위 편집기로 스크롤).
- 한계: 페이지 제목·칸 제목은 아직 그림 위가 아니라 📐 상자의 입력칸에서 고칩니다. AI 이미지 편집 결과의 **원본 도면 속 글자**(방 이름 등)는 이미지의 일부라 고칠 수 없고, 제목·범례처럼 편집 가능한 글자만 됩니다.

## 모든 결과의 도형을 고치기 (색·위치·곡선·선 종류)
- **어떤 방식으로 만든 결과든** 그림 속 도형을 하나씩 눌러 고칠 수 있습니다. 손스케치·자유 해석·분석 축측도·AI 이미지 편집은 앞에서 설명한 편집기(화살표·도형·구역 색 층)를 쓰고, **평면 다이어그램·배치 개념도·매스 과정도·층별 조닝도·프로그램 버블도**는 아래 "도형 편집기"를 씁니다(다이어그램을 만들면 오른쪽에 자동으로 나옵니다).
- **고르기**: 도형·선·원·글자를 **클릭**합니다(주황 점선 상자가 생김). 칩·아이콘처럼 여러 요소가 한 덩어리면 **Alt+클릭** 또는 오른쪽 **↑ 묶음 선택**으로 통째로 고릅니다. 맨 뒤 흰 배경도 눌러 색을 바꿀 수 있지만 끌어 옮기지는 않습니다.
- **고칠 수 있는 것**: ① **색** — 채움 색·선 색(견본 + 색 선택기, '없음')·글자 색, 묶음을 고르면 안의 도형 색을 한 번에 ② **위치** — 끌어서 옮기기(Shift: 수평·수직), 방향키 1칸 / Shift+방향키 5칸, 오른쪽 ←→↑↓ 버튼 ③ **곡선·모양** — 곡선(path)의 **사각 점(마디)과 동그라미(곡선 조절점)**를 끌기, **＋ 점 추가 / － 고른 점 빼기 / 직선↔곡선**, 직선(line)은 **∿ 곡선으로 바꾸기**, 다각형·꺾은선은 꼭짓점 끌기, 사각형은 모서리 끌어 크기, 원·타원은 반지름 점 끌기 ④ **선 종류·굵기·투명도** — 실선·파선·점선·일점쇄선·굵은 점, 굵기 0.5~14, 투명도 ⑤ **글자 크기**(글자를 골랐을 때).
- **지우기**: Delete(고른 요소를 숨김, Ctrl+Z로 복구). **"이 요소 처음 모양으로"**, **"모든 수정 처음으로"** 버튼으로 되돌립니다.
- **고친 모양은 SVG·PNG 저장과 페이지에 그대로 담깁니다.** 왼쪽 "글자 수정"이나 그림 위 더블클릭으로 **글자를 고쳐 다시 그려도 도형 수정은 유지됩니다**(그림 구조가 같을 때). 새로 만들거나 구조가 바뀌면 옛 수정은 적용하지 않고 "그림 구조가 바뀌어 예전 수정은 적용되지 않았습니다"라고 알려 줍니다.
- 한계: 해칭 무늬 채움(패턴)의 색은 바꿀 수 없고(없음/단색으로는 바꿈), 페이지 모드에서 도형을 고친 칸은 제목·칸 수(열 수)를 페이지에 맞춰 바꾸지 않고 고친 그대로 넣습니다. 복사한 요소를 다른 그림에 붙이면 그 그림에 없는 화살촉·무늬 정의는 함께 복사되지만, 아주 복잡한 묶음(여러 겹 변환)은 모양이 조금 다를 수 있습니다. 해칭·아이콘처럼 작은 요소가 많은 그림은 **상자 선택**이나 Alt+클릭(묶음)이 편합니다.

## AI 이미지 편집 결과에서 마음에 안 드는 부분만 다시 그리기
- AI 이미지 편집 결과(화살표·구역 색이 층으로 나뉜 결과) 위에 **"🔁 이 영역만 다시 그리기"** 막대가 나타납니다. 누른 뒤 **그림 위에서 다시 그릴 영역을 끌어서** 고르고(주황 점선 상자), 필요하면 **이 영역만의 추가 요청**(예: "화살표를 현관 쪽으로 이어서")을 쓰고 **"다시 그리기"**를 누르세요. **약 2~4분**(전체를 다시 만들 때의 5~7분보다 짧음).
- **영역 밖은 그대로**입니다. 이미 손으로 고친 화살표·구역 색·글자·넣은 이미지는 영역 밖에서는 건드리지 않습니다. 영역 안에서는 **옛 화살표를 지우고 새 화살표를 넣고**, **구역 색은 그 영역만** 새로 칠해집니다(경계는 6화소에 걸쳐 부드럽게 이어집니다). 새 화살표의 색은 지금 그림의 같은 계열 화살표 색에 맞춰지고, 범례는 그대로 유지됩니다.
- AI는 고른 영역에 **여유(약 12%, 최소 320px)를 더해 잘라** 그리므로 영역 가장자리의 방·건물은 일부만 보일 수 있습니다. 범례(색과 뜻)는 처음 만든 것을 그대로 지시해서 같은 색 의미로 그립니다. 결과가 또 마음에 안 들면 **영역을 바꾸거나 요청을 고쳐 다시** 하세요. **"↩ 영역 다시 그리기 되돌리기"**로 방금 다시 그리기 전 모습으로 한 단계 되돌립니다.
- 한계: 화살표·구역 색 층을 가진 결과에서만 됩니다(합성 그림 한 장으로 나온 결과는 층이 없어 안 됩니다). 같은 영역도 매번 다르게 나오며, 사진·3D 결과는 장면을 다시 그리지 않고 그 영역의 화살표·색만 바꿉니다.
- **화살표 읽기가 좋아졌습니다**: 얇은 점선(1~2화소 점)과 파선 조각을 이어 한 화살표로 읽고, 선에서 떨어진 **화살촉만 있는 덩어리**도 화살촉 있는 화살표로 남기며(점선 조각과 이어 붙임), 구역을 칠한 색 띠의 연한 면을 선으로 착각하지 않습니다. 저장해 둔 아파트 평면 결과에서 화살표가 덮는 비율이 71% → 83%로 올랐습니다.

## 내 이미지(사진·로고·스케치)를 다이어그램 칸에 넣기
- **방법 1 — 끌어다 놓기**: 이미지 파일을 **오른쪽 화면(또는 📄 페이지 배치의 칸)에 끌어다 놓습니다.** 놓기 전에 주황 점선 테두리와 "칸 N에 내 이미지가 들어갑니다" 안내가 뜹니다. 페이지 배치의 **다른 칸 위에 놓으면 그 칸에** 들어갑니다. **방법 2 — 버튼**: 오른쪽 위 **🖼️ 내 이미지 넣기**(파일 창에서 **여러 장을 한꺼번에** 고를 수 있습니다). **방법 3 — 붙여넣기**: 캡처(Win+Shift+S)하거나 웹에서 복사한 그림을 **Ctrl+V** 로 바로 붙여넣습니다(글자를 입력하는 칸에서는 글자가 붙습니다).
- **빈 칸**이면 그 이미지가 바탕이 되고, 그 위에 ＋ 화살표·＋ 글자 등을 얹어 다이어그램으로 고칠 수 있습니다(손스케치류 편집기). **이미 그림이 있는 칸**이면 그 그림 안 한가운데에 이미지가 놓입니다.
- 놓은 이미지는 **클릭해서 끌어 옮기고, 네모 모서리 점을 끌어 크기를 바꿉니다**(원본 비율 유지, Shift: 자유롭게). 오른쪽에서 **투명도**, **맨 뒤로(도형·화살표 아래) / 맨 앞으로**, **삭제**(Delete), 손스케치류는 **원본 비율로** 버튼과 좌표 입력도 됩니다. Ctrl+Z/Y로 되돌립니다.
- **여러 장을 한 번에**(최대 12장): **빈 칸에 놓으면 그 칸부터 칸 번호 순서대로 빈 칸을 하나씩 채웁니다**(끝에 닿으면 처음으로, 빈 칸이 모자라면 남은 것은 그 그림 안에 얹습니다). **그림이 있는 칸이나 빈 화면의 첫 이미지 뒤에는 모두 그 그림 안에 얹고**, 겹치지 않게 조금씩 비껴 놓습니다(끌어서 옮기세요). 읽지 못한 파일이 있으면 어떤 파일인지 알려 줍니다.
- PNG·JPG·WebP·GIF를 넣을 수 있고(SVG·PNG 저장과 페이지 출력에 그대로 들어갑니다), 이미지가 아닌 파일은 거부하고 안내합니다. 큰 사진을 줄여 담는 정도는 **🖼️ 버튼 옆 상자**에서 고릅니다: **가볍게(긴 변 1000px) / 보통(1600px, 기본) / 선명하게(2600px)**. 선명하게는 화질이 좋은 대신 큰 이미지가 여러 장이면 편집·페이지 미리보기가 느려질 수 있습니다. 넣은 뒤 안내에 크기(px)와 용량(KB)이 표시됩니다(선택은 이 브라우저에 기억됩니다).
- **이미지 바꾸기(🔄)**: 넣은 이미지를 고르면 오른쪽에 **🔄 이미지 바꾸기** 버튼이 있습니다. 다른 파일로 바꾸되 **옛 자리 안에 비율을 지켜 가장 크게(가운데 유지)** 놓이고, 투명도·맨 뒤/앞은 그대로입니다(자르기는 풀립니다). **자르기(✂)**: 원본 이미지가 열리고 **주황 상자**를 끌어(안쪽 = 옮기기, 가장자리·모서리 점 = 크기) 남길 부분을 고른 뒤 **적용**(Enter)합니다. **보이는 부분이 제자리에 남도록 상자가 줄어들고**, 다시 열면 원본에서 범위를 고칠 수 있으며 **전체로**를 누르면 자르기가 풀립니다(Ctrl+Z 도 됩니다). 참고: 저장한 SVG·PNG 파일에는 잘라 낸 그림만 들어가고, 원본은 작업 중인 이 화면에만 보관됩니다(그래서 저장 파일을 다시 열어 범위를 고치지는 못합니다).

## 글자를 누르면 몇 pt인지 알려 줍니다
- 다이어그램을 만든 뒤 **그림 속 글자를 한 번 클릭**하면 오른쪽에 **"🔤 ‘글자’ 약 N pt"** 상자가 뜹니다(제목·도형 이름·범례·메모 등 모든 글자, 손스케치류 메모는 크기 칸 옆에도 표시).
- **📐 페이지 모드를 켰다면** 그 칸이 실제로 저장되는 크기 기준입니다(칸에 맞춘 그림 배율과 "그림·글자 맞춤"으로 조정된 글자 배율이 반영되어, 📐 상자의 글자 위계 표와 맞습니다). **끄면** 저장한 그림 크기(96dpi) 기준이라 pt 값은 참고용이고, 페이지 크기를 정하면 그 용지에서의 pt로 바뀝니다.
- **글자 위계 판정(📐 페이지 모드일 때)**: pt 아래에 **글자 위계에 맞는지**가 초록(✔ 맞음) · 회색(ℹ 단계 사이) · 빨강(⚠ 경고)으로 뜹니다. **⚠ "읽기 어렵습니다"** — 이 용도의 최소 크기(인쇄 7pt, 화면 11pt)보다 작음. **⚠ "소제목(18pt)보다 크거나 같아 위계가 맞지 않습니다"** — 칸 제목·소제목·제목보다 큰 글자(윗 위계는 그 칸에 실제로 붙는 가장 낮은 것). **ℹ** — 본문·작은 글자 같은 단계 사이에 있어 한 단계로 맞추면 정돈됨. 고칠 수 있는 글자(구조형 결과의 글자, 손스케치 메모)는 **"N pt로 맞추기"** 버튼으로 바로 맞춥니다(Ctrl+Z 로 되돌림). 글자 크기를 직접 정한 값(📐 상자의 pt 입력)이 있으면 그 값이 기준입니다.

### 구조형 결과 편집기: 요소 추가 · 여러 개 선택 · 복사 · 정렬 (손스케치 편집기와 같은 수준)
- **요소 추가**(오른쪽 위 "요소 추가"): **＋ 글자 / ＋ 사각형 / ＋ 원 / ＋ 화살표 / ＋ 이미지**. 그림 한가운데에 놓이고 바로 선택됩니다. 새 글자는 내용 칸에 커서가 있어 바로 쓰고(줄바꿈 가능), 더블클릭으로도 고칩니다. 화살표는 화살촉이 선 색을 따라가며(끝·시작·양쪽·없음), 끝점과 곡선 점으로 모양을 고칩니다. 새 요소도 다른 요소와 똑같이 색·선 종류·굵기·투명도·위치를 고칩니다. 지울 때는 요소가 아예 사라지고(Ctrl+Z 로 복구), 모든 수정과 함께 SVG·PNG 저장에 담깁니다.
- **여러 개 선택**: **Shift(또는 Ctrl)+클릭**으로 더하고 빼며, **빈 곳(배경)을 끌어 만든 상자**에 통째로 들어온 요소가 선택됩니다(Shift 를 누르고 끌면 기존 선택에 더함). **Ctrl+A**: 모두. 고른 것 중 하나를 끌면 **모두 함께** 움직이고, 오른쪽 "N개 선택" 상자에서 **채움 색·선 색·굵기·선 종류·투명도**를 한꺼번에 바꾸고 방향 버튼으로 같이 옮깁니다. 방향키·Delete 도 모두에 적용됩니다.
- **복사·붙여넣기·복제**: **Ctrl+C / Ctrl+V / Ctrl+D**(또는 "복사·붙여넣기·복제" 버튼). 지금 **보이는 모양 그대로**(고친 색·위치, 묶음 안에 있던 요소의 위치·색, 화살촉·무늬 포함) 한 요소씩 새 요소가 되어 조금 비껴 붙고 붙여넣은 것이 바로 선택됩니다. 다른 칸의 그림에도 붙일 수 있고, 복사한 글자도 더블클릭으로 고칩니다. 내가 넣은 이미지도 복사됩니다.
- **정렬**: 여러 개를 고르면 **왼쪽·가운데·오른쪽·위·중간·아래**로 서로 맞추고, 3개 이상이면 **가로/세로 간격을 같게** 합니다. **하나만 고르면 그림 틀을 기준**으로 맞춥니다(예: 가운데 놓기).
- **자석과 안내선**: 요소를 끌면 다른 요소의 **변·가운데, 그림 가운데**에 5px 안쪽으로 가까워질 때 붙고 **분홍 점선 안내선**이 뜹니다. **Alt 를 누르고 끌면 자석이 꺼집니다.** Shift 끌기는 수평·수직 고정입니다.

### 회전 · 번호 마커 · 리더선 라벨 (두 편집기 공통, 2026-10-20)
- **회전**: 고른 요소 위의 **동그라미 손잡이**를 끌면 돕니다(Shift: 15° 단위 · Alt: 붙지 않음 · 그냥 끌면 45° 배수 근처에서 살짝 붙음). 속성 패널의 **각도(°) 입력, −90 / −15 / +15 / +90 단추, 0°(되돌리기)** 도 같습니다. 돌린 뒤 크기를 바꿔도 가운데 둘레로 다시 돕니다. **구조형 편집기는 여러 개를 골라 함께 돌리면 묶음의 가운데를 중심으로** 돕니다(손스케치 편집기는 한 번에 하나만 고르므로 하나씩). 번호 마커·리더선 라벨·해 아이콘은 글자가 기울지 않으므로 돌리지 않습니다.
- **＋ 번호**(요소 추가 줄): **검은 원 안의 흰 숫자**가 놓입니다. 놓을 때마다 **1, 2, 3…** 이 자동으로 붙고, **가운데 마커를 지우면 뒤 번호가 자동으로 당겨집니다**. 번호를 **직접 고치면(속성 칸 또는 숫자 더블클릭) 그 번호는 고정**되어 나머지 자동 번호가 건너뛰고, **↺ 자동**으로 되돌립니다. 모양은 **원 / 사각**, 크기·색(바탕)은 속성에서 고르며 밝은 바탕이면 숫자가 어두운 색으로 바뀝니다. 숫자는 최대 3자.
- **＋ 리더선**: **굵은 제목 + 밑줄 + 설명(줄바꿈으로 최대 3줄) + 끝점이 있는 안내선** 한 묶음이 놓입니다. 속성에서 **제목·설명, 선 종류(직선 / 꺾은선), 끝 모양(● 점 / ▶ 화살표 / 없음), 글자 크기, 색**을 고칩니다. **글 상자를 끌면 끝점까지 통째로** 움직이고(복사·붙여넣기·대칭 복제도 통째로), **끝점의 동그라미 손잡이**를 끌면 가리키는 곳만 바뀝니다. 제목·설명 글자를 **더블클릭해도 고칩니다(Enter 확정 · Shift+Enter 줄바꿈)**. 꺾은선은 가로로 나간 뒤 세로로 꺾이며, 끝점이 글 상자 안쪽·뒤쪽에 있으면 저절로 직선이 됩니다.
- 시험해 볼 것: ① 번호 4개를 놓고 2번을 지워 3·4가 2·3 으로 당겨지는지 ② 3번을 `1`로 직접 고쳐 나머지가 건너뛰는지 ③ 리더선을 놓고 끝점을 그림 위 한 곳에 맞춘 뒤 글 상자를 옮겨 보기 ④ 저장한 SVG·PNG 에 편집용 손잡이·점선 틀이 없는지.

### 아이콘 (아이콘 칩 · 배치 개념도 아이콘, 2026-10-20)
- 아이콘이 **기본 12개 → 110개**로 늘었습니다. 기본 12개(식물·해·나무·물·사람·벤치·주거·차량·거점·특화·산책로·건물)는 그대로 두고, **건축·도시 관련 98개**(구조·건물 / 설비·에너지 / 자연·환경 / 안전·방재 / 주거·생활 / 동선·방향 / 일반)를 오픈소스 **Lucide(ISC 라이선스, 상업 이용·수정 가능)** 에서 골라 넣었습니다. 라이선스 전문과 원본은 `third_party/lucide/` 에 있습니다.
- **＋ 아이콘**(두 편집기 "요소 추가" 줄): 색 칩 안에 아이콘이 놓입니다. 속성에서 **아이콘 고르기(분류 탭 + 한국어·영문 검색, 예: "주차", "bus")**, **모양(둥근 사각 / 원 / 아이콘만)**, 크기, 색(아이콘만이면 아이콘 색)을 고칩니다. 칩은 돌리지 않고, 복사·붙여넣기·정렬·저장 대상입니다.
- **배치 개념도(AI)**: 위치 표시(marker)의 아이콘을 AI 가 **110개 목록 안에서** 뜻이 가장 가까운 것으로 고릅니다(예: 지하주차장 → square-parking). 목록에 없는 이름을 쓰면 별(star)로 대신하고, 대소문자·`_` 차이는 알아서 맞춥니다.
- 시험해 볼 것: ① 아이콘 5개를 놓고 분류 탭을 넘기며 바꿔 보기 ② 검색칸에 "물", "주차", "bus" ③ 모양을 "아이콘만"으로 바꿔 색을 주기 ④ 배치 개념도를 만들 때 설명에 "주차·버스정류장·학교"가 들어가면 그에 맞는 아이콘이 나오는지.

### 개요표 (＋ 표, 2026-10-20)
- 두 편집기 "요소 추가" 줄의 **＋ 표**: 건축개요 예시가 든 **라벨–값 표**가 놓입니다(제목 + 행 4개). 지원 범위는 **2~4열, 두 스타일, 행 목록 + 더블클릭 편집**이며 **병합 셀·계산·간트는 지원하지 않습니다**.
- **편집**: 속성 패널에서 **표 제목, 열 수(2·3·4), 스타일, 행 목록**(칸마다 입력, 행 ▲▼ 순서·× 삭제, ＋ 행 추가, 최대 30행)을 고치고, **그림에서 칸·제목을 더블클릭**해도 바로 고칩니다(빈 칸도 됩니다, Enter 확정). 글자 크기와 색(제목 띠·선)은 슬라이더·색 선택으로 바꿉니다.
- **스타일**: ① **회색 라벨 열 + 가는 선**(건축개요형 — 첫째 열이 회색 바탕의 굵은 글자, 4열이면 셋째 열도 라벨 열) ② **색 띠 + 줄무늬**(면적표형 — 제목을 색 띠로, 줄무늬 행, 숫자·㎡·% 같은 값은 오른쪽 맞춤).
- **열 너비**는 글자 길이에 맞춰 **저절로** 정해집니다(제목이 더 길면 표가 제목 폭에 맞춰집니다). 열을 줄이면 오른쪽 열 내용이 잘리니, 늘렸다 줄일 때 주의하세요.
- 표는 끌어서 옮기고 복사·붙여넣기·정렬·저장(SVG·PNG)이 됩니다. 돌리지는 않습니다.
- **엑셀·한글 표 붙여넣기(v2, 2026-10-20)**: 표 속성 맨 위 **"엑셀·한글 표 붙여넣기"**(접힘)를 열고 칸에 **Ctrl+V** 하면 지금 표가 붙여넣은 표로 바뀝니다(스타일은 유지). 엑셀·한글·웹의 **HTML 표**, 탭·쉼표(CSV)·`|`(마크다운)·공백 두 칸 이상으로 나뉜 글자를 읽고, **첫 줄이 한 칸짜리면 표 제목**이 됩니다. 4열을 넘으면 오른쪽 열이, 30행을 넘으면 아래 행이 잘리며 안내가 뜹니다(병합 셀은 빈 칸으로 채움).
- **개요표 칸(v2)**: 왼쪽 **종류**에서 **"개요표 (라벨–값 표)"** 를 고르면 표 하나로 칸을 채우는 결과를 만듭니다 — **"예시 표로 시작"**, 또는 설명으로 AI 가 채우기("건축개요표를 만들어줘. 건폐율 59.8%…", 종류가 자동이어도 개요표·면적표를 달라는 말이면 이 종류로 만듭니다), 만든 뒤 **"표 내용 수정"** 에서 행·열·스타일·글자 크기·색과 엑셀 붙여넣기를 고칩니다. 페이지 모드에서는 칸 하나를 채우고, 그 위에 이미지·리더선 등을 더 얹을 수도 있습니다. 병합 셀·계산·간트·조직도는 여전히 지원하지 않습니다(범위 안내가 뜹니다).
- 시험해 볼 것: ① 4열·라벨형으로 건폐율/용적률/높이/층수를 넣기 ② 줄무늬형으로 면적표(숫자 오른쪽 맞춤) ③ 칸 더블클릭으로 고치고 Enter ④ 행을 위로·아래로 옮기기 ⑤ 저장한 SVG·PNG 에 점선 틀이나 눌림 영역이 보이지 않는지.

### 내 이미지를 흐린 바탕으로 (🌫 맥락 바탕, 2026-10-20)
- **내 이미지**(＋ 이미지·끌어다 놓기·붙여넣기로 넣은 사진·스케치·지도)를 고르면 속성에 **투명도 · 탈색 · 가장자리 흐리게** 슬라이더가 있습니다. **탈색 100% = 흑백**, **가장자리 흐리게**는 가장자리에서 안쪽으로 서서히 진해지게 합니다(100%면 사진의 4분의 1 가까이가 번집니다).
- **🌫 맥락 바탕으로 흐리게** 단추 한 번: **흑백 + 투명도 35% + 맨 뒤로**. 매스 과정도(대지 맥락)나 평면 위에 동선·구역을 얹을 때 **대지·주변 사진을 흐린 회색 바탕으로 깔고 그 위에 도형·화살표를 올리는** 용도입니다. **효과 지우기**로 처음 모양으로 돌아갑니다.
- 원본 이미지는 그대로 두고 **SVG 필터·마스크로 겹쳐 그리므로 언제든 다시 바꿀 수 있습니다**(손스케치·구조형 편집기 공통). 저장한 SVG·PNG 에도 그대로 나옵니다. 일러스트레이터에서는 "SVG 필터" 효과로 열리며, 효과를 굽고 싶으면 PNG 로 저장하세요.
- 시험해 볼 것: ① 대지 사진을 넣고 🌫 단추 → 그 위에 매스·화살표 놓기 ② 가장자리 흐리게 50~70% 로 흰 보드에 자연스럽게 녹이기 ③ 돌린 이미지에도 같은 효과가 되는지 ④ 페이지 칸 여러 개에 같은 이미지 효과를 써도 서로 섞이지 않는지.

## 카드 보드 (기술·상품 계획 요약 보드, 2026-10-20 v1)
사내 도집 형식(핵심 가치 띠 + 큰 그림 + 카드 격자)을 한 장으로 만듭니다. **AI 가 구조(제목·불릿·아이콘 이름)만 정하고, 글자 줄바꿈·배치·그리기는 프로그램이 해서 글자가 깨지지 않고 계속 고칠 수 있습니다.**
- **시작하기**: 왼쪽 **종류**에서 **"카드 보드"** 를 고르면 **시작 틀** 선택이 나옵니다 — ① **계획 요약형**(핵심 가치 5개 + 히어로 그림(좌우 설명·개요표) + 카드 6개, 구조·토목 등) ② **설비·시스템형**(핵심 가치 6개 + 좌우 아이콘 목록 + 카드 12개 2줄). 설명(분야와 핵심 내용)을 쓰고 **✨ 다이어그램 만들기**, 또는 AI 없이 **"예시 내용으로 시작"** 으로 틀의 예시를 바로 불러옵니다. 종류를 "자동"으로 두고 "구조계획을 카드 보드로 정리해줘"처럼 써도 카드 보드로 만듭니다.
- **내용 수정**: 왼쪽 아래 **"카드 보드 내용 수정"**(접힘)을 열면 **띠별로** — 핵심 가치(번호·제목·설명·아이콘, 괄호형/번호 탭형, 항목 추가·삭제), 히어로(안내 글·이미지·좌우 아이콘 목록), 카드 줄(머리색 4종·열 수·카드 제목·부제·머리 아이콘·**그림 칸 0~3개**(아이콘 / 내 이미지 / 빈 칸)·작은 이름·불릿 2줄, 카드 추가·삭제·앞뒤 이동 — **보드 전체 12장까지**)을 고칩니다. 띠를 더하고 빼고 위아래로 옮길 수도 있습니다. **그림 위 글자는 더블클릭**해도 고칩니다(폼에도 바로 반영).
- **이미지 넣기**: 히어로 그림 자리와 카드의 "내 이미지" 칸에 **🖼 이미지 넣기**로 파일을 고릅니다. 맞춤은 **꽉 채우기(잘라서)** / **전체 보이기**. 이미지를 넣으면 점선 안내 칸은 사라집니다(안내 칸 자체를 끄는 설정도 있습니다). 아이콘 칸은 아이콘 110개 중에서 고릅니다.

- **칸 배치 추가**: **3×3 (9칸)**, **위 4칸 + 아래 와이드 칸**(위 소도식 4개 + 아래 큰 칸).
- 시험해 볼 것: ① 방위표를 돌려 북쪽을 맞추고 PNG 로 저장해 N 이 같이 돌았는지 ② 축척 막대의 칸 수·길이·단위를 바꿔 눈금이 맞게 나뉘는지 ③ 긴 제목에 오른쪽 위 라벨을 넣어 겹치지 않는지 ④ 새 칸 배치에 그림 넣기.

## 출력 크기 · 칸 나누기 · 글자 위계 (📐 상자, 다이어그램 탭 왼쪽)
- **"정해진 크기의 페이지에 맞춰 만들기"를 켜면** 어떤 방식으로 만든 다이어그램이든(손스케치·AI 이미지 편집·평면 다이어그램·배치 개념도·매스 과정도 …) 정한 가로×세로(mm) 안에 맞춰 넣고, **SVG는 그 mm 크기 그대로** 저장됩니다(일러스트레이터에서 열면 아트보드가 그 크기). PNG는 96/150/300dpi 중에서 고릅니다.
- **📐 상자는 꺼져 있어도 설정이 모두 보입니다**(흐리게). 위 체크를 켜기 전에 크기·글자·여백을 미리 정해 두면 기억되고, **"지금 켜기"** 를 누르면 그 설정으로 페이지가 만들어집니다. 칸 나누기·칸 선택·고른 칸의 위치/크기는 켠 뒤에 나타납니다.
- **용지**: A4·A3·A2·A1 가로/세로, PPT 16:9·4:3, 직접 입력(mm). 가로·세로 바꾸기 버튼이 있고, 용도(인쇄/화면)에 따라 글자 추천이 달라집니다.
- **칸 나누기**: 1칸(한 장 전체), 좌우 2칸, 위아래 2칸, 가로·세로 3칸, 2×2, 3×2, 2×3, "큰 칸 1 + 작은 칸 2~3" 같은 배치, 또는 가로×세로 칸 수를 직접 지정(최대 6×6). 칸 사이 간격(mm)도 정합니다. **칸 하나를 눌러 고른 뒤 "다이어그램 만들기"를 누르면 그 칸에 들어갑니다**(칸 버튼에 그 칸의 mm 크기가 적혀 있고, 페이지 미리보기에서 칸을 직접 눌러도 됩니다). 칸마다 다른 그림을 넣을 수 있고 "선택한 칸 비우기"로 뺄 수 있습니다. 여러 칸이면 각 그림의 제목이 **칸 제목(소제목 크기)** 으로 칸 위에 붙습니다.
- **편집기에서 복사한 요소를 페이지 칸에 바로 붙여넣기**: 편집기에서 요소를 골라 **복사**(버튼 또는 Ctrl+C)한 뒤, **페이지 미리보기에서 붙여넣을 칸을 클릭**하고 **Ctrl+V** 하면 됩니다(칸을 누른 뒤에는 편집기 안을 다시 누르지 않아도 됩니다). 칸에 따라 이렇게 붙습니다 — ① **그림이 있는 같은 종류 칸**(손스케치↔손스케치, 구조형↔구조형): 그 칸의 그림에 복사한 요소가 **새 요소로 추가**되고(조금 비켜서, 여러 번 누르면 또 붙음), 붙인 뒤 바로 고를 수 있습니다. ② **빈 칸**: 복사한 요소 **부분이 보이는 그림**으로 들어갑니다(영역 복사와 같은 방식 — 위쪽에 "전체 보기" 안내). ③ **다른 종류의 그림이 있는 칸**: 붙지 않고 "붙여넣을 수 없습니다" 안내만 뜹니다(실수로 덮어쓰지 않게). 칸 복사·영역 복사와 섞어 써도 **가장 나중에 복사한 것**이 붙습니다. 편집기 안에서 Ctrl+V 하면 예전처럼 그 그림에 바로 붙습니다.
- **손스케치 "정렬·대칭"의 대칭축은 좌우(세로선)·상하(가로선)를 따로 고릅니다**: "대칭축" 상자에서 **그림 가운데 / 가장 큰 도형 가운데**를 고르면 좌우 대칭은 그 도형의 가운데 **세로선**, 상하 대칭은 가운데 **가로선**을 기준으로 합니다. 가장 큰 도형이 그림 가로 가운데에만 있거나 세로 가운데에만 있어도 상자가 나옵니다. **중심축 보기**를 켜면 "가장 큰 도형 가운데" 선택 시 그 도형의 축도 함께 보입니다.
- **왼쪽 설정 패널에 "③ 도형 편집" 탭이 있습니다**: 편집기의 **요소 추가 · 그림 속 도형 고치기 · 정렬 · 선택한 요소의 속성** 카드가 이제 편집기 안이 아니라 **왼쪽 패널의 ③ 도형 편집 탭**에 나옵니다(① 만들기 · ② 페이지 · ③ 도형 편집, 카드 보드·개요표가 있으면 ④ 구성 수정). 그래서 가운데 편집기는 **그림만 전체 폭**으로 보입니다(764px 폭에서 그림 450px → 753px). **편집기에서 요소를 누르면 ③ 탭이 자동으로 열리고**, 다른 탭을 보고 있을 때는 편집기 아래에 "도형 편집 열기" 안내가 나옵니다. 그림이 없는 칸에서는 ③ 탭에 안내 글만 나옵니다. **◀ 설정 접기**로 왼쪽 패널을 접으면 카드는 예전처럼 편집기 안(넓으면 그림 오른쪽, 좁으면 그림 아래)에 나타납니다. 손스케치·구조형 모두 같습니다.
- **테스트 버튼(AI 없이 바로 시험)**: ① 만들기의 "다이어그램 만들기" 바로 아래 **"테스트: 만든 것처럼 바로 보기"** 를 누르면, 페이지 모드가 켜지고 **"위 큰 칸 + 아래 띠 3칸"** 칸 4개에 예시 그림(**손스케치** · 배치 개념도 · 프로그램 버블도 · 층별 조닝도)이 들어간 채로 ② 페이지 화면이 바로 열리고, 첫 칸(손스케치)이 왼쪽 편집기에 열립니다. 다이어그램이 만들어질 때까지 기다리지 않고 페이지 배치·영역 복사·그림 크기·파선 간격 같은 화면 기능을 시험할 때 씁니다. 누르기 전 상태는 **Ctrl+Z** 로 되돌릴 수 있습니다(실제 AI 호출은 없습니다).
- **페이지 모드는 항상 "왼쪽 편집기 | 오른쪽 페이지 배치"로 나란히 보입니다**: 왼쪽은 **고른 칸의 편집기**(도형·글자를 바로 고침), 오른쪽은 **[📄 페이지 배치 · 칸 크기 조절]**(칸을 끌어 크기·위치를 바꾸는 미리보기, 스크롤해도 따라다님)입니다. 칸이 비어 있으면 왼쪽에 안내가 나옵니다.
- **나란히 보기(위아래로 보기는 없앴습니다)**: 화면 폭과 상관없이 항상 왼쪽(편집기)과 오른쪽(페이지 배치)이 **같은 폭(1:1)** 으로 나란히 보입니다 — 예전의 "화면 배치" 선택 상자와 가운데 선(손잡이)은 없앴습니다. **그림이 있는 칸을 고르든 빈 칸을 고르든 배치가 바뀌지 않습니다** — 빈 칸을 고르면 왼쪽 편집기 자리에 "칸 N은 비어 있습니다" 안내와 **"예시 그림 넣기"**·(복사해 둔 것이 있으면) **"복사한 그림 붙여넣기"** 버튼이 나옵니다. 화면이 좁아 편집기가 약 664px 미만이 되면 속성 패널이 그림 아래로 내려갑니다(넓히려면 아래 **◀ 설정 접기**·**⤢ 편집 집중**).
- **편집을 크게 하기 (편집기가 작을 때)**: 편집기는 그림 칸 + 오른쪽 속성 패널(290px)로 이루어져 있어서, 화면이 3등분(설정 | 편집기 | 페이지)되면 그림이 작아집니다. 세 가지로 키웁니다.
  1. **⤢ 편집 집중 (단축키 F)** — 페이지 위쪽의 버튼이나 **F 키**(입력칸에 글자를 쓰는 중이 아닐 때)로 켭니다. **편집기가 오른쪽 화면 전체 폭**이 되고, 페이지 배치는 위쪽의 **작은 띠**(지금 모습의 축소 그림 + **칸 번호 버튼 · ◀ ▶**)로 줄어듭니다. 띠의 축소 그림이나 번호로 다른 칸을 고르면 그 칸의 편집기가 같은 크기로 열리고, 빈 칸이면 안내가 나옵니다. 칸 크기·페이지 제목 고치기는 **"⤡ 나란히 보기로 (F)"** 로 돌아가서 합니다. 선택은 기억됩니다.
  2. **◀ 설정 접기** — 왼쪽 설정 패널(340px)을 접어 오른쪽 화면을 넓힙니다. 패널의 **◀ 접기** 버튼이나 페이지 위쪽의 **"◀ 설정 접기"** 로 접고, 왼쪽의 **▶ 설정 열기** 띠로 다시 펼칩니다(접어도 입력한 내용·이미지는 그대로). 화면이 넓어지면 "자동" 배치가 나란히 보기로 바뀔 수 있습니다. 기억됩니다.
  3. **확대·이동(줌)** — 편집기(손스케치·구조형 모두) 위의 작은 줄에서 **− 100% ＋ 맞춤 ✋ 이동**. **Ctrl+마우스 휠**(터치패드는 두 손가락 벌리기)로 마우스가 가리키는 곳을 중심으로 100%~400% 확대합니다. 확대한 뒤에는 **Space를 누른 채 끌기**, **마우스 가운데 버튼 끌기**, 또는 **✋ 이동**을 켜고 끌어서 그림을 옮겨 보며(끄면 다시 요소를 끌어 고칩니다), 휠로도 스크롤됩니다. 확대해도 도형 끌기·손잡이·글자 고치기·안내선은 그대로 정확합니다. 확대 배율은 칸을 바꾸면 100%로 돌아옵니다.
- **페이지 제목을 그 자리에서 고치기**: 페이지 미리보기에서 **제목·소제목 글자를 한 번 누르면** 그 자리에 입력칸이 열립니다(Enter 확정 · Esc 취소). 제목이 없으면 **위쪽 여백**에 마우스를 올리면 "＋ 제목 추가"가 뜨고, 제목이 생기면 그 아래에 "＋ 소제목 추가" 자리가 생깁니다. **칸 제목(여러 칸일 때 칸 위의 소제목 크기 글자)은 더블클릭**합니다(그 칸의 그림 제목이 바뀝니다. 손으로 고친 구조형 결과는 칸 제목이 붙지 않습니다). 한 칸짜리 페이지에서 제목이 그림 자체의 제목이었다면 지워도 그림 제목이 함께 비워집니다. 칸 제목을 고친 것은 페이지 되돌리기(Ctrl+Z)로 되돌립니다.
- **보드 틀(사내 보드 형식, 2026-10-20)**: 📐 상자 맨 아래 설정과 칸 설정으로 참고 보드 같은 틀을 만듭니다.
  - **칸 배치 4개 추가**: *위 큰 칸 + 아래 띠 3·4·5칸*, *왼쪽 세로 4칸 + 오른쪽 큰 칸*(칸 나누기 목록).
  - **칸 라벨**: "칸 라벨 접두어"를 STEP / ISSUE / 배치전략으로 고르면 칸 위에 **"─── STEP 01 ───"** 선 사이 라벨이 붙습니다. 큰 그림 칸(작은 칸의 2배 이상)은 번호를 건너뛰고 **작은 칸이 01부터** 받습니다. 칸을 고르면 아래에 **그 칸의 라벨(↺ 자동으로 되돌리기)과 설명**(칸 제목 아래 최대 2줄, 칸이 작으면 생략) 입력칸이 나옵니다. 미리보기에서 **라벨·칸 제목·설명을 더블클릭**해도 바로 고칩니다(라벨을 비우면 그 칸만 숨김). 그림을 다른 칸으로 옮기면 설명도 따라가고, Ctrl+Z 로 되돌립니다.
  - **구분 라벨 · 제목 강조 · 꼬리말**: 제목 위에 `| 구조계획 |` 작은 글자(눌러서 고침), 제목에 `{중괄호}`로 감싼 말은 **강조색(기본 주황) 굵게**(예: 공원 속 {체육센터}), 오른쪽 아래 **꼬리말 `프로젝트명  02`**(쪽번호는 숫자 입력, 두 자리로). 아래 여백이 좁으면 알려 줍니다. 구분 라벨·쪽번호·칸 설명은 제목처럼 기억하지 않고, 프로젝트명·라벨 접두어·강조색은 기억합니다.
  - **페이지 모드의 바탕은 항상 흰 종이**: 손스케치 개념도의 크림 바탕이 흰 보드에 번지지 않습니다(한 칸 페이지도 같음). 단독 저장은 예전처럼 크림색.
  - **새 페이지의 기본 글씨체는 Pretendard**입니다. 이미 저장해 둔 설정은 그대로이니 필요하면 "글씨체"에서 직접 고르세요. **Pretendard 는 이 PC에 설치돼 있어야** 미리보기·PNG에 나오고, 없으면 맑은 고딕으로 대신 그려집니다(설치된 PC에서 열면 SVG 는 Pretendard).
- **칸의 그림을 다른 칸으로 옮기기·맞바꾸기**: 왼쪽 📐 상자의 칸 목록 아래, 고른 칸에 그림이 있으면 **"↔ 이 그림을 다른 칸으로…"** 상자가 나타납니다. 도착 칸을 고르면 **빈 칸은 그림이 이동**하고(원래 칸은 비워짐), **그림이 있는 칸은 서로 맞바꿉니다**(고르는 목록에 "옮기기"/"서로 맞바꾸기"로 적혀 있습니다). **칸 목록의 버튼(● 채워진 칸)을 끌어서 다른 칸 버튼 위에 놓아도** 같습니다. 옮긴 뒤 도착 칸이 선택되고, 칸 크기가 다르면 그림이 새 칸에 맞춰 다시 배치되며, **Ctrl+Z**(페이지 되돌리기)로 되돌립니다. 참고: 페이지 미리보기에서 칸을 끄는 것은 칸의 위치·크기만 바꾸고 그림은 옮기지 않습니다. 예전에는 Ctrl+C → 도착 칸 선택 → Ctrl+V 로 복사한 뒤 원래 칸을 비우는 방법뿐이었고, 도착 칸에 그림이 있으면 묻지 않고 덮어썼습니다(지금도 Ctrl+V 는 그렇게 동작).
- **칸을 직접 끌어서 크기 조절**: 오른쪽 **페이지 미리보기**에서 칸을 누르면 주황 테두리와 **가장자리 점 8개**가 생깁니다. 점을 끌면 크기가 바뀌고(끄는 동안 칸의 mm 크기가 표시됨), **칸 사이 경계선을 끌면 그 선에 맞닿은 칸이 함께** 바뀝니다(2×2에서 가운데 선을 끌면 네 칸이 같이 변함). **Alt를 누르고 끌면 그 칸 하나만** 바뀝니다(칸이 겹칠 수 있음). **칸 안쪽을 끌면 칸이 옮겨지고**, 다른 칸의 가장자리·페이지 가운데·바깥 가장자리에 3mm 안쪽으로 가까워지면 **붙습니다**. 칸은 최소 25mm입니다. 끌고 나면 칸 나누기가 "✋ 직접 조정한 배치"로 바뀌고 그림이 새 크기에 맞춰 다시 그려집니다. 왼쪽 상자에는 고른 칸의 **X·Y·가로·세로(mm)** 입력, **칸 좌우로/위아래로 나누기**, **칸 삭제**(최대 12칸, 비운 자리는 이웃에 합쳐지지 않음), **배치 되돌리기**(처음 고른 칸 나누기로)가 있습니다.
- **바깥 여백(가장자리 간격)**: 기본은 자동(인쇄 8mm 이상·짧은 변의 4%)이고, "직접 입력"을 고르면 **위·아래·왼쪽·오른쪽을 mm로** 정합니다("네 변 같게"를 끄면 변마다 따로). 한 변은 용지의 30%까지입니다. 제목·소제목·칸 전체가 이 여백 안쪽에 놓입니다. **테두리선**을 켜면 페이지 가장자리에서 정한 간격(비우면 가장 작은 여백의 절반)만큼 안쪽에 둘레선(굵기 pt, 색 선택)을 그립니다. 프린터가 못 찍는 가장자리(보통 4~5mm)와 제본 여백을 생각해 정하세요.
- **단축키**(화면에는 안내 목록을 두지 않았고 기능만 있습니다): **Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z)** 페이지 되돌리기·다시 하기(칸 끌기·숫자 입력·나누기·삭제·비우기·붙여넣기, 60단계), **Delete** 고른 칸 비우기(**Shift+Delete** 칸 삭제), **방향키** 고른 칸 이동 1mm(Shift 10mm)·**Alt+방향키** 크기 1mm(Shift 10mm), **Tab / Shift+Tab** 다음·이전 칸 고르기, **Esc** 끌던 동작 취소, **Ctrl+C / Ctrl+V** 칸 내용 복사·붙여넣기, **Ctrl+D** 칸 내용을 빈 칸에 복제, **Ctrl+S / Ctrl+Shift+S** SVG·PNG 저장, **Ctrl+Enter** 다이어그램 만들기(설명을 쓰는 중에도). 페이지 단축키는 **페이지 미리보기나 설정 상자를 마지막으로 눌렀을 때** 적용되고, **손스케치 편집기를 눌렀을 때는 편집기의 단축키**(요소 Ctrl+Z·Delete·방향키 등)가 적용됩니다. 입력칸에 글자를 쓰는 중에는 Ctrl+Enter·Ctrl+S 외에는 무시됩니다.
- **글자 위계 풀이**: 네 단계입니다. ① **제목**(페이지 제목, 가장 큼·굵게 Bold) ② **소제목**(페이지 소제목과 여러 칸일 때 각 칸 위의 **칸 제목**, 중간 굵기 Medium) ③ **본문**(다이어그램 속 블록 이름·칩·범례 같은 글자, 보통 Regular) ④ **작은 글자**(각주·보조 범례). 항상 제목 > 소제목 > 본문 > 작은 글자 순이어야 하고, 입력칸의 흐린 숫자가 이 용지의 추천값입니다. 직접 넣은 값이 거꾸로(예: 제목 6pt·소제목 40pt)면 **빨간 경고**가 뜹니다("추천값으로 되돌리기"로 바로잡기). 아주 작은 용지에서도 추천값은 이 순서를 지킵니다.
- **칸에 맞춰 만들기**: 평면 다이어그램·배치 개념도·매스 과정도처럼 패널이 여러 개인 그림은 **칸의 가로세로 비율에 맞게 한 줄에 놓는 패널 수를 자동으로** 정합니다(세로로 긴 칸은 1줄에 1개, 가로로 긴 칸은 여러 개). 그림 둘레의 빈 여백은 잘라 내서 칸을 알뜰히 씁니다.
- **글자 위계(pt)**: 용지에 맞춰 **제목 / 소제목 / 본문(다이어그램 속 글자) / 작은 글자(범례·각주)** 를 추천합니다. 인쇄는 A3 기준 32/18/11/8pt를 짧은 변에 비례해 키우고 줄이고(A4 23/13/8/6pt, A1 64/36/22/16pt), 화면은 PPT 16:9 기준 36/22/14/11pt입니다. 추천값은 입력 칸에 흐리게 보이고, 직접 숫자를 넣으면 그 값이 우선합니다. **제목·소제목(칸 제목)은 이 pt로 그립니다.**
- **다이어그램 속 글자는 그림이 정한 크기라서** pt를 직접 지정할 수는 없고, 칸에 맞춘 뒤의 **실제 pt**를 계산해서 "지금 결과 ○○pt"로 보여 드립니다. 너무 작으면(인쇄 7pt 미만, 화면 11pt 미만) 빨간 경고와 함께 칸을 키우거나 내용을 줄이라고 알려 줍니다. "그림 맞춤"을 "본문 글자를 목표 pt에 맞추기"로 바꾸면 칸을 꽉 채우지 않고 본문이 목표 pt가 되도록 그림 크기를 정합니다.
- **그림 속 글자는 본문 목표 pt에 자동으로 맞춰집니다(기본)**: "그림·글자 맞춤"의 권장 방식은 **그림은 칸에 꽉 맞는 배율 그대로 두고, 그림 속 모든 글자에 같은 비율을 곱해** 가장 많이 쓰인 글자(본문)가 목표 pt(예: A3 11pt)가 되게 합니다. 그림 속 글자끼리의 크기 차이(패널 제목 대 블록 이름)는 유지되고, 글자의 가운데 위치도 유지됩니다. 그래서 큰 칸에 작게 그려진 그림에서도 글자가 소제목보다 커지지 않고 제목 > 소제목 > 본문 순서가 지켜집니다. 글자를 키울 때는 칸 밖으로 넘칠 수 있어 **최대 1.3배**, 줄일 때는 **0.3배**까지만 바꿉니다(그 안에서 목표에 못 닿으면 "지금 결과 ○○pt"로 알려 줍니다). 다른 방식: "칸을 꽉 채우기(글자 크기는 그림 배율을 따름)", "본문 글자를 목표 pt에 맞추기(그림을 줄임, 칸이 남음)". 사진·AI 이미지 편집 결과 속의 글자(원본 그림에 박힌 글자)는 그림의 일부라 바뀌지 않고, 제목·범례처럼 편집 가능한 글자만 조정됩니다.
- **글씨체**: 맑은 고딕(기본), Noto Sans KR, Pretendard, 나눔고딕, 돋움, 바탕 중에서 고르면 제목·그림 속 글자 전부에 적용됩니다. 용도별 사용 권장(고딕 한 종류로 통일, 제목 굵게/소제목 중간/본문 보통)이 같이 나옵니다. **저장한 SVG는 그 글꼴이 설치된 PC에서 열어야 그대로 보입니다**(없으면 비슷한 글꼴로 바뀜).
- 설정은 이 브라우저에 기억됩니다(제목·소제목 입력 칸은 기억하지 않음). "예시 그림 넣어 보기" 버튼으로 AI 없이 크기·칸·글자 위계를 먼저 만져 볼 수 있습니다.
- 한계: 칸 크기는 칸 나누기 프리셋과 격자만 되고 칸을 끌어서 크기를 바꾸거나 칸을 합치는 편집은 아직 없습니다. 칸을 고른 뒤 만드는 AI 단계는 칸 크기를 모르고 만든 다음 칸에 맞추는 방식입니다(패널 수 배열만 칸 비율에 맞춰짐). 그래서 그림의 가로세로 비율이 칸과 다르면 **그림이 칸 안에서 가로폭 또는 세로폭에 맞춰지고 나머지 방향에 여백이 남습니다**(예: 가로로 긴 평면도를 거의 정사각형 칸에 넣으면 위아래가 비고, 같은 칸에서 글자도 그만큼 작아짐). 칸 비율을 그림에 맞추려면 칸 가장자리를 끌어 비율을 바꾸세요.

## 이상하게 나왔을 때 남겨 주실 것
1. **원본 스케치 이미지**를 `모델링/` 폴더에 저장합니다(파일 이름에 간단한 메모를 붙여 주세요. 예: `3_파랑단색_물결선.jpg`). 이 폴더는 외부 저장소에 올라가지 않습니다.
2. 결과 화면의 **캡처**를 같이 저장합니다.
3 한 줄로 **무엇이 틀렸는지** 적습니다. 예) `세로 판이 회색 코어가 됨`, `왼쪽 화살표 하나 빠짐`.

이렇게 모인 그림이 정확도를 재는 평가 자료가 됩니다. 모인 그림으로 고치고, 고친 뒤에도 이전에 되던 것이 그대로 되는지 자동으로 다시 확인합니다.

## 유료 옵션 (키를 연결한 뒤에만 보입니다)
- 키가 없으면 아래 버튼은 **화면에 나타나지 않습니다**(정상). 모든 유료 호출은 누를 때만 실행되고, 확인창에 예상 비용(원)과 누적 사용액이 뜹니다. **누적 총 한도 10,000원**을 넘기는 호출은 서버가 막습니다.
- **🔎 유료로 만들기**(손스케치·분석 축측도): 이름·설명·바람 방향 붙이기(손스케치) 또는 바람·일조·문구 정하기(분석 축측도)를 상위 Gemini 모델로 합니다. 필요한 설정: `GEMINI_PAID_API_KEY`, `GEMINI_PAID_VISION_MODEL`.
- **🎨 유료로 매끈하게 다시 그리기**(분석 축측도 결과가 있을 때): 지금 결과(글자 뺀 초안)와 내 도면·참고 이미지를 이미지 생성 모델에 보내 새로 그립니다. 그 그림이 바탕이 되고 오른쪽 문구는 편집 가능한 글자로 얹힙니다. 마음에 안 들면 **벡터 버전으로 되돌리기**. 필요한 설정: `OPENAI_API_KEY` 또는 `GEMINI_IMAGE_API_KEY`. 이미지가 외부 서버로 전송됩니다.
- 이미 있는 **정밀 읽기**(손스케치·자유 해석)와 조감도 유료 생성도 같은 누적 한도에 합산됩니다.

## 알아 두면 좋은 점
- **무료 Gemini**로 읽습니다. 한꺼번에 많이 시도하면 한도(429)에 걸려 `HTTP 500`이 날 수 있습니다. 잠시 뒤 다시 누르면 됩니다.
- 설명과 이미지는 **외부(Google Gemini)로 전송**됩니다. 대외비 자료는 올리지 마세요.
- 유료 정밀 읽기는 키를 연결하기 전이라 **버튼이 보이지 않습니다**(정상입니다).
- 읽기가 완벽하지 않아도 결과 화면에서 **끌어서 고칠 수 있습니다**. 목표는 "고칠 곳이 한두 군데뿐인 초안"입니다.
- 이 도구가 아직 못 하는 것: 사진을 비스듬히 대고 찍어 **사다리꼴로 찍힌 경우(원근 왜곡)**, 종이 **구김**, 그림 밖의 **배경이 크게 같이 찍힌 경우**는 충분히 시험하지 못했습니다. 이런 사진이 어떻게 나오는지도 알려 주세요.

## 다이어그램 전체 크기 조절 (2026-10-20, R10)
- **어디서**: 구조형 편집기(배치 개념도·매스·버블도·조닝도·카드 보드·개요표 …)와 **손스케치 편집기** 둘 다.
- **구조형**: **Ctrl+A**(또는 옆 패널의 **전체 선택** 단추, 빈 곳을 끌어 상자로 고르기, Shift+클릭) → 고른 것 전체를 감싸는 주황 상자의 **네 모서리 손잡이**를 끈다. 반대쪽 모서리는 제자리에 있고 **글자·선 굵기·화살촉까지 같은 비율**로 커지거나 줄어든다. 끄는 동안 `NN%`가 뜨고, **Shift를 누른 채 끌면 가로·세로를 따로**(글자는 찌그러지지 않게 작은 쪽 비율). 옆 패널에 **80% / −10% / +10% / 125%** 단추. 번호 마커·아이콘·리더선·표·방위표·축척 막대·넣은 이미지도 함께 바뀐다.
- **손스케치**: **'전체 크기' 단추 또는 Ctrl+A** → 내용 전체를 감싸는 상자와 모서리 손잡이. 같은 비율로만 조절(옆 패널에 80%/−10%/+10%/125%, **원래 크기로**, 끝내기). 제목·범례·오른쪽 설명 칸은 그대로 두고 그림 속 도형·선·화살표·글자·표·이미지·바탕은 함께 바뀐다. 그림을 직접 누르면 전체 모드가 끝난다.
- **알아둘 것**: 배율은 0.05~20배. 크기를 바꾼 뒤에도 요소를 끌어 옮기고 손잡이로 고치고 돌릴 수 있다. 되돌리기(Ctrl+Z) 한 번에 한 번의 끌기가 돌아간다. 페이지 모드의 '그림·글자 맞춤'은 이 위에 따로 적용된다.

## 사내 디자인 적용 (2026-10-20)
- 선택 기록은 프로젝트 루트 `DESIGN_CHOICE.md`(도구형 · 라이트·부드럽게 · AX LAB 로고 · 건축 언어 · 앱 전체). 상단 **헤더(작은 AX LAB 로고 + 밑줄 모듈 탭 + 오른쪽에 버전·갱신일 글자와 프로젝트 알약 단추)**, 연한 블루 회색 바탕 위 흰 입력창, 평면 버튼(블루 단색), 토스트는 오른쪽 아래. 화면 장식 이모지는 모두 뺐고 결과가 없는 화면에는 로고 격자 선화 마크가 나온다.
- 글꼴은 `Pretendard`가 설치된 PC에서는 그것을, 없으면 맑은 고딕을 쓴다(Pretendard 파일은 앱에 넣지 않았다).

## 글자 정렬 · 자간 · 행간 (2026-10-20, R11)
- **구조형(배치 개념도·매스·버블도·카드 보드 등)**: 글자를 클릭 → 오른쪽 패널 **글자 정렬(왼쪽·가운데·오른쪽) / 자간 / 행간**. 정렬을 바꿔도 **글자는 제자리**에 있고 줄 맞춤만 바뀝니다. 행간은 **여러 줄로 된 글자**에만 보입니다. 여러 글자를 함께 고르면 정렬·자간을 한꺼번에. 리더선 라벨에는 글 상자 안 줄 맞춤·자간·설명 행간이 있습니다.
- **손스케치**: 글자 메모에 정렬·자간, 리더선에 정렬·자간·설명 행간.
- **페이지(② 페이지 > 세부 설정 > 머리·꼬리)**: **제목·소제목 정렬**(왼쪽·가운데·오른쪽)과 **자간**. 오른쪽 위 도면 라벨 옆에서도 겹치지 않게 제목 폭 안에서 맞춰집니다.
- 되돌리기: 구조형은 '처음으로', 슬라이더를 0(자간)·100%(행간)로 되돌리면 원래대로입니다.

## 치수선 (2026-10-21)
- 구조형·손스케치 모두 요소 추가의 **＋ 치수선**. 양 끝의 주황 점을 끌어 길이·방향을 맞추고(구조형은 Shift 로 가로·세로 고정), 치수 글자(예: `12,000`, `30m`)는 **더블클릭**해서 적습니다. 글자 크기·색은 오른쪽 패널. 글자는 선을 따라 기울어도 항상 읽히는 방향입니다. 단위·축척을 자동으로 계산하지는 않으니 숫자는 직접 적습니다.

## 칸 복사·붙여넣기 (2026-10-21)
- ② 페이지가 켜져 있을 때 오른쪽 페이지 미리보기 위의 **칸 복사 / 칸에 붙여넣기 / 빈 칸에 복제**. 복사할 칸을 고르고 **칸 복사**, 붙여넣을 칸을 고르고 **칸에 붙여넣기**(그림이 있던 칸은 바뀌며 Ctrl+Z 로 되돌립니다). **빈 칸에 복제**는 비어 있는 첫 칸에 바로 복제합니다. 미리보기를 누른 상태에서 Ctrl+C / Ctrl+V / Ctrl+D 도 같습니다.

## 전체 이동 (2026-10-21)
- 구조형: Ctrl+A 등으로 여러 개를 고른 뒤 **주황 상자 안쪽 아무 곳(요소·배경·빈 곳)을 끌면 전체가 함께 이동**합니다. 빈 곳을 끌지 않고 누르면 선택이 풀립니다.
- 손스케치: Ctrl+A 또는 `전체 크기`를 누른 상태에서 **그림 위를 끌면 내용 전체가 이동**합니다(Shift: 수평·수직). 끌지 않고 누르면 전체 모드가 끝나고 그 도형이 선택됩니다.
- 손스케치: **아무것도 없는 빈 곳을 끌면 그림 전체가 움직입니다**(Ctrl+Z 로 되돌림). 도형·글자를 끌면 그 하나만 움직입니다.
- 손스케치의 전체 이동·전체 크기 조절은 **제목·소제목·범례·설명 칸 글자까지 포함한 그림 전체**(바탕만 제외)에 적용됩니다.

## SVG 로 저장해서 일러스트레이터로 열 때 (2026-10-21)
- **SVG 저장**은 일러스트레이터가 읽는 옛 규격(`xlink:href`)으로 저장합니다. 그림의 이미지는 파일 안에 이미 들어 있어서 따로 연결 파일을 같이 받을 필요가 없고, 일러스트레이터에서 "연결된 파일을 찾을 수 없다"가 뜨지 않게 고쳤습니다. 화살촉 색도 일러스트레이터가 읽는 형태로 바꿔 저장합니다.
- 바깥 주소를 가리키는 이미지가 있으면 저장할 때 안내가 뜹니다(그 이미지는 다시 넣어 주세요). 글자 둘레 흰 테두리나 이미지 흐림 효과는 일러스트레이터에서 다르게 보일 수 있습니다.

## 그림 전체 선택(테두리) · 종류 직접 고르기 (2026-10-21)
- **그림의 빈 곳(바탕)을 한 번 누르면 그림 전체가 선택**되어 주황 테두리와 네 모서리 손잡이가 나옵니다. 모서리를 끌면 크기, 상자 안쪽(손스케치는 빈 곳)을 끌면 위치가 바뀝니다. 다시 누르면 선택이 풀립니다. 구조형에서는 이 선택에서 **바탕 색**도 바꿀 수 있습니다.
- **'만들 수 있는 것 · 없는 것 (종류 안내)'**: 설명만으로 만드는 종류는 **이 종류로**, 이미지를 올려 만드는 방식은 **이 방식으로**를 눌러 직접 고릅니다(고르지 않으면 AI가 자동 판단). **자동 판단으로 되돌리기**로 취소합니다.
  - 소재 이미지를 올린 채 **이 종류로**를 누르면: **배치 개념도**는 이미지의 배치를 읽어(또는 "이미지 그대로 바탕"이면 그대로 깔고) 만들고, **매스 과정도**는 건물 형태를 읽어 만듭니다. **개요표·층별 조닝도·프로그램 버블도·카드 보드**는 이미지에 보이는 글자·항목을 읽어 채웁니다(소재 이미지 아래 **내용 읽기** 버튼이 켜지고, 위의 "종류" 칸에서 이 4종 중에서 고릅니다). 표 캡처·단면도·평면도·계획 문서를 올리면 되고, 보이지 않는 값은 지어내지 않게 AI에 지시합니다. 설명(1번)에 "면적표 위주로"처럼 적으면 그 지시를 따릅니다. 결과는 클릭해서 그대로 고칠 수 있습니다.
- **칸 안의 그림을 직접 끌어 크기·위치 조절(페이지 미리보기)**: 그림이 있는 칸을 고르면 **그림에 딱 맞는 파란 점선 상자**가 나오고 네 모서리에 **둥근 파란 점**이 붙습니다(눈에 안 보이는 투명한 부분은 빼고 실제로 보이는 곳만 잽니다). 모서리 점을 끌면 **맞은편 모서리를 붙잡아 둔 채** 그림 전체(도형·글자)가 한 장의 그림처럼 같이 커지고 줄어듭니다(20%~200%, 끄는 동안 "그림 크기 80%" 표시). **점선 상자의 테두리를 끌면** 그림이 칸 안에서 옮겨집니다. 칸 크기는 그대로이고(칸 크기는 네모 점), 100%를 넘기면 칸을 넘는 부분은 잘립니다. 놓으면 확정, Esc 는 취소, Ctrl+Z 는 되돌리기이고, 점을 더블클릭하거나 위쪽 **"그림 크기 N% · 칸에 맞춤"** 버튼을 누르면 처음으로 돌아갑니다. 칸마다 따로 저장되고(한 칸짜리 페이지도 됩니다) 저장하는 그림에도 같은 크기·위치로 들어가며, 칸 사이에 그림을 옮기면 같이 따라갑니다. (예전의 "그림 크기" 슬라이더 막대는 뺐습니다.)
- **영역 복사 → 다른 칸에 붙여넣기(버튼 없이 단축키로)**: ① 그림 위에서 **Shift+드래그**로 영역을 잡습니다 — 아래 **편집 화면**의 빈 곳(바탕)에서도, **페이지 미리보기**의 칸 안에서도 됩니다(점선 상자가 남고 두 화면에 같이 보입니다). ② **Ctrl+C** 로 복사합니다(Esc 는 해제, 끄는 중 Esc 는 취소). ③ 붙여넣을 **칸을 클릭**하고 ④ **Ctrl+V** 하면 **그 칸에는 고른 영역만 확대되어 보입니다**(상세도처럼). 도형 위에서 하는 Shift+드래그·Shift+클릭은 예전처럼 편집기가 받고(여러 개 고르기·수평/수직 고정), 영역을 안 잡았을 때의 Ctrl+C·Ctrl+V 는 예전처럼 **칸 전체** 복사·붙여넣기입니다. 붙여넣은 그림은 원본과 따로라서 그림 전체를 계속 편집할 수 있고(편집 화면은 전체), 그 칸 위쪽에 "이 칸에는 그림의 일부 영역만 보입니다" 안내와 **"전체 보기"** 버튼이 나옵니다. 위쪽 **"영역 복사"** 버튼(누르고 끌면 바로 복사)도 그대로 있습니다.
- **다이어그램 탭은 들어올 때마다 "① 만들기" 화면으로 시작합니다**(처음 열 때·새로고침·다른 탭에 갔다가 돌아올 때). 같은 탭 안에서 ② 페이지·③ 구성 수정으로 옮겨 다니는 것은 그대로입니다.
- **파선 간격 조절**: 선을 고르면 선 종류 아래에 **"파선 간격 N%"** 슬라이더가 나옵니다(30%~400%, 선 조각 길이는 그대로 두고 쉬는 칸만 늘고 줄어듭니다). 구조형(평면 다이어그램·배치 개념도·매스·버블도·층별 조닝도)에서는 AI 가 그린 "8 6" 같은 **선 종류에 없는 파선도** 처음 모습을 100%로 삼아 바뀌고, 여러 개를 고르면 **"파선 간격(모두)"** 로 한꺼번에 바꿉니다(도형마다 자기 간격을 지킴). 손스케치는 직선과 화살표(선 표현이 파선·점선·일점쇄선일 때)에 같은 슬라이더가 있습니다. 실선이면 슬라이더가 숨습니다.
- **페이지 배치 · 칸 크기 조절은 끄는 동안 그림이 바로 바뀝니다**: 고른 칸의 가장자리·모서리 점을 끌면 칸 안의 그림이 그 크기에 맞춰 **끄는 즉시** 다시 놓여 보입니다(예전에는 점선 상자와 mm 숫자만 움직이고 그림은 마우스를 놓아야 바뀌었습니다). 놓으면 그 모습이 그대로 확정되고, Esc 를 누르면 끌던 것을 취소해 원래대로 돌아갑니다. 칸을 옮기는 끌기도 마찬가지입니다.
- **새로고침해도 괜찮습니다(AI 이미지 편집 = 도면 위 표시)**: 3~6분 걸리는 작업은 서버가 계속하므로, 새로고침하거나 다른 탭에 갔다 와도 다이어그램 화면을 다시 열면 **자동으로 이어서 받아** 결과를 그려 줍니다(서버가 작업을 기억하는 최대 약 1시간, 서버를 재시작했으면 "이어받지 못했습니다" 안내). 이어받은 결과도 "이 영역만 다시 그리기"까지 그대로 됩니다. 만들거나 읽는 중에 새로고침·탭 닫기를 하면 브라우저가 한 번 물어봅니다. (그 밖의 만드는 중 작업은 짧아 이어받기 없이 물어보기만 합니다.)
- **'이미지 → 깔끔한 선' 탭은 뺐습니다**(2026-10-21 요청). 다이어그램 화면은 '다이어그램 만들기' 하나만 남아 위쪽 탭 줄도 없앴습니다.
