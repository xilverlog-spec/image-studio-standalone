# 손스케치 → 다이어그램 직접 테스트 안내

직접 써 보시고 결과를 알려 주시면 정확도를 더 올리는 데 가장 큰 도움이 됩니다. **잘 안 된 그림이 가장 귀한 자료**입니다.

## 시작하기
1. 사내 주소(백엔드, 5000번 포트)로 접속하고 **Ctrl+F5**로 새로고침합니다.
2. **다이어그램 탭 → 2. 소재 이미지**에 손스케치 사진을 올립니다.
3. 이미지 종류에서 **손스케치(펜으로 그린 개념 스케치)** 를 고릅니다.
4. **1. 설명**에 개념을 한 줄 적습니다. 예) `판상형 맞통풍 구조` — 도형 이름과 바람 방향, 제목을 이 문장대로 붙입니다.
5. **미리 읽어서 확인하기**를 누르면 읽은 모습을 먼저 볼 수 있고, **다이어그램 만들기**를 누르면 이름·제목까지 붙여 완성합니다.
6. 결과 화면에서 도형·화살표·선을 **끌어서 고치고** **SVG 저장**으로 내려받습니다.

## 이런 그림을 시험해 주세요
| 시험 | 알고 싶은 것 |
|---|---|
| 휴대폰으로 **비스듬히·그림자 지게** 찍은 사진 | 사진 조건에 강한지 |
| 종이에 **작게** 그려서 사진에 넓게 찍힌 그림 | 그림 부분만 잘라 읽는지 |
| **파란 펜만** 쓴 그림(물결선 바람 표시 포함) | 물결선을 읽는지 |
| **빨간 펜** 화살표·호·열린 면 표시가 있는 그림 | 화살표·호·열린 면을 읽는지 |
| 코어(빗금)가 **여러 개**이거나 붙어 있는 그림 | 판/코어 구분 |
| **탑상형·ㄱ자·중정형** 등 다른 구도 | 한 가지 구도에만 맞춘 게 아닌지 |
| 같은 그림을 **두 번** 읽혀 보기 | 결과가 매번 비슷한지 (읽기 결과는 같은 그림이면 저장되어 재사용되고, **다시 읽기**를 누르면 새로 읽습니다) |

## 결과를 볼 때 확인할 것
- 판(큰 사각형)과 코어(회색 상자)의 **개수·위치·크기**가 맞는가
- 화살표의 **시작·끝·방향**, 호, 물결선(바람)이 그림과 같은가
- 칸막이 선이 엉뚱한 곳에 없는가
- 열린 면(주황 점선)이 **맞는 변**에 있는가
- 글자(OPEN 등)와 제목이 알맞은가

## 이상하게 나왔을 때 남겨 주실 것
1. **원본 스케치 이미지**를 `모델링/` 폴더에 저장합니다(파일 이름에 간단한 메모를 붙여 주세요. 예: `3_파랑단색_물결선.jpg`). 이 폴더는 외부 저장소에 올라가지 않습니다.
2. 결과 화면의 **캡처**를 같이 저장합니다.
3 한 줄로 **무엇이 틀렸는지** 적습니다. 예) `세로 판이 회색 코어가 됨`, `왼쪽 화살표 하나 빠짐`.

이렇게 모인 그림이 정확도를 재는 평가 자료가 됩니다. 모인 그림으로 고치고, 고친 뒤에도 이전에 되던 것이 그대로 되는지 자동으로 다시 확인합니다.

## 알아 두면 좋은 점
- **무료 Gemini**로 읽습니다. 한꺼번에 많이 시도하면 한도(429)에 걸려 `HTTP 500`이 날 수 있습니다. 잠시 뒤 다시 누르면 됩니다.
- 설명과 이미지는 **외부(Google Gemini)로 전송**됩니다. 대외비 자료는 올리지 마세요.
- 유료 정밀 읽기는 키를 연결하기 전이라 **버튼이 보이지 않습니다**(정상입니다).
- 읽기가 완벽하지 않아도 결과 화면에서 **끌어서 고칠 수 있습니다**. 목표는 "고칠 곳이 한두 군데뿐인 초안"입니다.
- 이 도구가 아직 못 하는 것: 사진을 비스듬히 대고 찍어 **사다리꼴로 찍힌 경우(원근 왜곡)**, 종이 **구김**, 그림 밖의 **배경이 크게 같이 찍힌 경우**는 충분히 시험하지 못했습니다. 이런 사진이 어떻게 나오는지도 알려 주세요.
