# 상지건축 AI 이미지 스튜디오 — 직원용 사용 안내 (한 장)

## 어떤 도구인가
- **조감도 탭**: 모델링 캡처 이미지를 사진 같은 조감도로 바꿉니다(분위기 렌더 / 입면 비교 / 참조 이미지 적용).
- **다이어그램 탭**: 설명(과 이미지)으로 개념 다이어그램을 만듭니다. 결과는 **SVG**로 저장되어 일러스트레이터에서 글자·선까지 고칠 수 있습니다.
- **이미지 → SVG 변환**: 가진 도식 이미지를 깨끗한 선의 SVG로 바꿉니다.

## 조감도 탭
### 이지 모드 (처음 쓴다면 이것)
1. 이미지를 넣습니다. **첫 번째가 원본(형태 기준)**, 나머지는 **참조(최대 3장)** 입니다. 순서는 ▲▼로 바꿀 수 있습니다.
2. 하고 싶은 말을 한글로 씁니다. 참조가 있으면 역할을 같이 적어 주세요.
   - 예) `이미지 2는 건물 외관을 참고하고, 이미지 3은 재료를 참고해서 오션뷰 카페로 만들어줘`
3. **외부 전송 동의**에 체크하고 **조감도 생성**을 누릅니다. 조감도는 **유료 엔진(Google)** 으로만 만들어지며, 이미지가 외부 서버로 전송되고 한 장에 약 $0.13(약 180원, 추정)이 듭니다. 엔진을 고르는 칸은 없습니다.

### 프로 모드
작업 방식, 입면·분위기 여러 장 한 번에, 참조별 역할과 "이 사진에서 가져올 것"을 직접 고릅니다. 엔진은 이지 모드와 같이 Google 유료 엔진으로 정해져 있고, 장수를 늘리면 그만큼 요금이 듭니다.

### 잘 나오게 쓰는 요령
- 원본은 **건물이 잘 보이는 각도**의 캡처가 좋습니다. 형태는 원본을 따라갑니다.
- 참조는 **재료·입면 분위기**만 가져옵니다. 건물 형태는 원본 것이 유지됩니다.
- 시간대는 따로 안 정하면 "화창한 오후"로 만듭니다. 다른 분위기는 프로 모드에서 고르거나 글로 적습니다.
- 간판·로고 글자는 입면을 크게 바꾸면 깨질 수 있습니다. 최종본 전에 확인하세요.
- 결과가 마음에 들면 **이어서 수정**(예: `1층 유리를 더 크게`)으로 조금씩 고칠 수 있습니다.
- 결과 옆의 **형태 점수**는 원본 형태가 얼마나 유지됐는지 보는 **거친 참고값**입니다. 조명·색이 바뀌면 점수가 흔들리니, 점수보다 **눈으로** 보세요.

### 알아 둘 점
- 조감도는 이 PC의 그래픽 대기열을 거치지 않고 외부 서버(Google)에 바로 요청합니다.
- 프로젝트가 **외부 전송 금지**로 설정되어 있으면 조감도를 만들 수 없습니다(화면에 안내가 나옵니다). 외부 전송을 허용해도 되는 자료인지 먼저 확인하세요.
- 이미지가 **외부 서버로 전송**되고 장당 요금이 듭니다. 대외비 자료는 쓰지 마세요.
- 관리자가 정한 **사용액 한도**에 닿으면 더 만들 수 없습니다. 화면의 사용액 표시를 확인하세요.

## 다이어그램 탭
1. 설명을 씁니다. 종류는 **자동**이면 AI가 고릅니다.
   - 배치 개념도(흐름·정원·순환) / 매스 과정도 / **프로그램 버블도**(공간 구성·관계) / **층별 조닝도**(층별 프로그램·보이드·채광)
2. 내 건물·도면 이미지를 **소재 이미지**로 넣으면 형태를 읽어서 그 위에 그립니다. 이런 느낌으로 만들고 싶은 이미지는 **스타일 참고**로 넣습니다.
3. 결과의 **글자 수정**에서 AI를 다시 부르지 않고 글자를 바로 고칠 수 있습니다. **요청 반영 점검**에서 빠진 항목은 "빠진 항목 넣어서 다시 만들기"로 보충합니다.
4. **SVG 저장**으로 내려받습니다.
- 만든 다이어그램은 **이 브라우저에 자동 저장**되어 새로고침해도 남습니다(손으로 고친 내용 포함). 다른 PC나 다른 주소(예: `localhost`와 사내 IP)에서는 보이지 않으니, 남길 결과는 **SVG 저장**으로 내려받으세요. 새로 시작하려면 **저장된 작업 지우기**를 누릅니다.
- 설명과 이미지는 외부(Google Gemini)로 전송됩니다. **대외비 자료는 올리지 마세요.**

### 손스케치 → 다이어그램 (바로 고치기)
1. **소재 이미지**에 펜으로 그린 개념 스케치 사진을 올리고, 이미지 종류에서 **손스케치**를 고릅니다.
2. 설명(1번)에 개념을 한 줄로 씁니다. 예) `판상형 2개 동, 남북 맞통풍`
3. **다이어그램 만들기**를 누르면 그려진 상자·빗금·선을 정돈하고, 개념에 맞게 이름과 화살표 방향을 붙입니다.
4. 그림의 **화살표·선·도형·글자를 클릭**하면 오른쪽에 속성이 나타납니다.
   - 화살표: 화살촉(끝/시작/양쪽/없음), 굵기, 색, 양끝 문구, 위치, 방향 뒤집기
     - **선 표현**: 실선 / 파선 / 점선 / 일점쇄선 / 이중선 / **리본(붓 띠)** / **번짐(끝이 흐려지는 띠)** / 화살표 반복 / 물결 장식선
     - **곡선 모양**: 읽은 모양(다듬음) / **S자 곡선** / 호 / 직선, 그리고 곡선 세기·휘는 정도 슬라이더(음수는 반대쪽으로 휨)
   - **끌어서 편집**: 요소를 끌어 이동, 선택하면 나타나는 네모 점으로 크기 조절, 동그라미로 화살표 끝점 이동, **큰 마름모로 S자 변곡점(꺾이는 가운데 지점)을 자유롭게 이동**, 작은 빈 마름모로 휘는 정도 조절(변곡점은 '변곡점 가운데로 되돌리기'로 복원)(Shift: 수평·수직 고정, Alt: 자석 끄기, 방향키: 미세 이동)
   - **복사·붙여넣기**: 요소를 선택하고 **Ctrl+C → Ctrl+V**(누를 때마다 조금씩 비껴 붙음), **Ctrl+D**는 바로 복제, **Ctrl+X**는 잘라내기. 패널의 복제·복사 버튼도 같습니다.
   - 도형: 판/코어/**개구부(창, 점선 캡슐)** 종류, 이름·설명, 채움색, 위치·크기
   - 위쪽 **＋ 화살표/선/도형/개구부/글자**로 새로 추가, **Delete** 키 또는 삭제 버튼으로 삭제, **Ctrl+Z**로 되돌리기
   - 아무것도 선택하지 않으면 **스타일(개념도 주황 / 도면용 흑백)**, 제목·부제, 하단 범례·핵심 메시지 표시를 바꿀 수 있습니다. 기본은 **개념도 스타일**(크림 배경, 주황 점선·화살표, 회색 코어 안에 이름, 큰 제목)입니다.
   - 도형을 선택하면 **'열린 변'(위·아래·왼쪽·오른쪽)** 을 체크해서 그 변의 외곽선을 따라 주황 점선을 켜고 끌 수 있고, **'벽에서 안쪽 간격'**(0이면 외곽선과 정확히 겹침)을 조절합니다. 스케치의 빨간 눈금 표시는 자동으로 열린 변으로 읽힙니다. 짧게 따로 떨어진 표시는 개구부로 남으며 **'가까운 벽에 붙이기'** 로 벽에 붙일 수 있습니다.
   - 도형을 선택하면 **'도형 안에 이름 표시'** 로 이름을 도형 안에 쓸지 정합니다(코어는 기본으로 표시).
5. **SVG 저장**을 누르면 지금 보이는 모습 그대로 SVG로 저장됩니다(일러스트레이터에서 글자·선까지 편집됩니다).
- **펜 색을 구분해서 읽습니다.** 건물은 검정·파랑, 방향·개방 표시는 **빨간 펜**으로 그리면 화살표(방향까지), 호, 손글씨(예: OPEN), 벽에 붙인 빨간 빗금(개구부)이 각각 편집 가능한 요소로 들어옵니다.
- 읽기는 같은 그림을 **3번 읽어 가장 일치하는 결과**를 쓰므로 1~2분 걸립니다. 읽은 모습이 틀리면 클릭·끌기로 고치세요(도형이 쪼개져 읽히면 크기 조절점으로 합치거나 삭제).
- 새 그림을 올릴 때는 **설명도 새로 쓰세요**(설명이 남아 있으면 제목·이름이 이전 문장대로 붙습니다).
- 바람 방향과 "서풍/북풍" 같은 이름은 AI의 추측이니 실제 대지에 맞게 꼭 확인하고 고치세요.
- **다이어그램 만들기를 다시 누르면 새로 만들어서 직접 고친 내용은 사라집니다.** 고친 뒤에는 SVG 저장을 먼저 하세요.

## 이미지 → SVG 변환
- 도식 종류(선 / 색 블록 / 3D 캡처)를 자동으로 판별해 맞는 방식으로 바꿉니다. 3D 캡처는 AI가 선화로 다시 그린 뒤 벡터로 바꿉니다.
- 칸이 여러 개인 시트는 칸마다 따로 처리합니다.
- 나무·사람이 많은 복잡한 장면은 선이 일부 어긋날 수 있습니다. 결과를 열어 확인하세요.

## 문제가 생기면
| 증상 | 확인 |
|---|---|
| 조감도 탭에 "사용할 수 있는 유료 엔진이 없습니다" | 결제가 연결된 키가 서버에 없거나 프로젝트가 외부 전송 금지입니다. 관리자에게 알려 주세요. |
| 생성이 실패하고 결제·잔액 관련 오류가 보인다 | 충전한 크레딧이 소진됐을 수 있습니다. 관리자에게 알려 주세요(자동으로 무료로 바뀌지 않습니다). |
| 오래 걸린다 | 외부 서버가 처리합니다. 몇 분이 지나도 끝나지 않거나 오류가 나면 관리자에게 알려 주세요. |
| "부적절한 내용" 오류 | 글에 걸러지는 단어가 있습니다. 표현을 바꿔 다시 시도하세요(건축 용어도 가끔 오탐됩니다 — 관리자에게 알려 주세요). |
| 결과 형태가 많이 바뀜 | 원본을 더 정면에 가깝게, 요청을 짧고 구체적으로 쓰세요. "건물 모양은 그대로"를 적어도 됩니다. |
