# 스타일 안(색·글씨체·위계) 비교·적용 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 다이어그램 결과(단독 또는 페이지 전체)를 다 만든 뒤 "스타일 안 비교" 창에서 안 3개(지금 모습 · 참고 A형 · 먹색 정돈형)를 같은 그림으로 나란히 보고 눌러서 적용·되돌린다.

**Architecture:** 새 순수 모듈 `src/conceptDiagram/theme.js` 가 안 3개와 `applyTheme(svg, themeId)`(색 계열 치환 + 글꼴 치환)를 갖는다. 렌더 직후·`applyEdits` 직전(결과 그림, 페이지 칸 조립, 손스케치 편집기)에 끼우고, 페이지 조립은 `inkColor`·`titleK` 옵션을 받는다. 비교 창은 새 컴포넌트 `ThemeCompare.jsx` 이고 썸네일은 같은 그림에 안마다 `applyTheme` 한 문자열이다(AI·재그리기 없음). 안 id 는 쪽 설정 `pg.theme` 한 곳에 두어 기존 `cd_page_v1` 저장에 같이 실린다.

**Tech Stack:** React 19(JSX) + Vite, 순수 JS 모듈, 회귀 점검 `node scripts/regression/check_diagrams.mjs`(rolldown 번들 → `m.*` 로 접근), 테스트 화면(하니스) 확인.

**Spec:** `docs/superpowers/specs/2026-10-26-스타일안-design.md` (사용자 승인 2026-10-26). 근거 통계 `docs/다이어그램탭_개선점_및_카드보드_설계안.md` 7부.

## Spec deltas (이 계획이 명세와 다르게 정한 것 — 구현 전에 알려 둔다)
1. **안 id 저장 위치**: 명세 5.4 의 `result.theme` 대신 **`pg.theme` 하나**(쪽 설정, 단독 결과에도 같은 값 적용). 이유: 범위가 "전체에 한 번에"라 결과마다 따로 저장할 필요가 없고, `pg` 는 이미 `cd_page_v1` 에 저장된다.
2. **무채색 판정 보정**: 명세 5.1 은 "채도 0.15 미만 = 무채색, 명도 0.2 미만 무채색 = ink". 앱의 어두운 청회색 글자색(`#1f242b` 채도 0.16)이 청색 계열로 오분류되므로 **"채도 < 0.15 이거나 (명도 < 0.3 이고 채도 < 0.35)"를 무채색**으로 본다.
3. **'지금 모습'의 글씨체**: 명세 표의 "맑은 고딕"은 틀림(새 쪽의 기본 글씨체는 Pretendard). 지금 모습은 **글씨체를 건드리지 않는다**(`fontId: null`).
4. **글꼴 설치 확인**: `document.fonts.check` 는 시스템 글꼴 설치 여부를 못 가르므로 **캔버스 글자 폭 비교**로 판정한다.

## Global Constraints
- 사내 디자인 규칙(`CLAUDE.md`): 색·모서리·그림자는 `src/index.css` 토큰만, **그라데이션·반투명 유리(backdrop-filter)·이모지 아이콘·hover 로 떠오르는 카드 금지**, 굵기 700 초과 금지(여기서는 600·700만), 브랜드 블루 외 강조색 금지(앱 UI 한정 — 그림 안 색은 예외). 아이콘은 `src/Icon.jsx` 스프라이트.
- 안은 **3개**: `current`(지금 모습) · `blue`(참고 A형) · `mono`(먹색 정돈형).
- 안 값(명세 §4): `blue` a1 `#DFA837` a2 `#2F4E9A` a3 `#7BA23A` ink `#231815` 글씨체 `pretendard` titleK 1.1 / `mono` a1 `#E8832A` a2 `#5F6670` a3 `#8A9097` ink `#1F2328` 글씨체 `noto` titleK 1. `current` 는 색·글씨체 변경 없음, titleK 1.
- 색 계열(HSL 색상각): 15~70° = a1, 70~165° = a3, 165~255° = a2, 그 밖(빨강·보라·분홍)과 무채색은 그대로. 기준색(명도·채도 비교): a1 `#F28C28`, a2 `#1E90C8`, a3 `#3E8E41`.
- 바꾸는 속성: `fill` `stroke` `stop-color` `flood-color` 속성 값과 `style="…"` 안의 `#RRGGBB` 만. 이미지 데이터·`url(#id)` 참조·`data-handle`(편집 손잡이)이 붙은 태그는 건드리지 않는다.
- 항상 **새로 그린 SVG 에서 시작**한다(이미 안이 입혀진 SVG 에 다시 입히지 않는다). 구조 지문(`scanSvg().sig`)은 색에 영향받지 않아 `edits` 는 그대로 유효하다.
- 응답·화면 글은 한국어. 문서·메모에 프로젝트명을 쓰지 않는다. 커밋은 사용자가 요청할 때만(자동 백업이 올린다) — 아래 "Commit" 단계는 **변경 묶음 확인용 체크포인트**이며 `git commit` 은 사용자 요청 때만 한다.

  - 소문자 hex 입력도 처리하고 결과는 대문자 `#RRGGBB`.
