- 프론트엔드: Vite 기반 React 앱(src/App.jsx, src/main.jsx, src/index.css)이 단일 페이지 스튜디오 UI를 구성.
- 백엔드: Python FastAPI 서버(backend/server.py)가 backend/routes/media.py, backend/routes/chat.py 등 라우트를 노출하고, backend/comfyui_client.py를 통해 로컬/원격 ComfyUI 인스턴스(기본 http://localhost:8188)와 통신해 이미지 생성을 수행. backend/services/에 이미지 히스토리 저장(image_history_store.py), 간단한 챗 서비스(simple_chat.py) 존재.
- 이미지 생성 워크플로: comfyui_workflows/ 하위에 flux_kontext_gguf, flux_schnell_gguf, sdxl_turbo용 ComfyUI 워크플로 JSON을 미리 정의해 백엔드에서 사용.
- 참고/부속 자산: Fooocus-main(서드파티 Stable Diffusion UI) 소스 전체가 저장소 내 하위 디렉터리로 함께 커밋되어 있음(직접 실행 종속성인지 단순 참고용인지는 추가 확인 필요).
- 이미지 블렌딩(변형/재생성) 기능: `backend/comfyui_client.py`의 `blend_images_or_raise`가 Fooocus의 Image Prompt 패널과 동일하게 슬롯(최대 4개) 단위로 타입(PyraCanny/CPDS=구조 유지용 ControlNet, ImagePrompt/FaceSwap=스타일 참고용 IP-Adapter)과 Stop At/Weight를 독립적으로 받아 ComfyUI 워크플로우를 동적으로 구성한다(2026-09-02). 구조 슬롯이 하나라도 있으면 완전 재생성(denoise=1.0)으로, 없으면 기본 이미지 latent에서 부분 denoise로 시작한다. `is_fooocus_advanced_settings_available()`로 감지되는 `FooocusAdvancedSettings` 커스텀 노드(Fooocus 이식 코드)가 설치돼 있으면 Adaptive CFG/Sharpness/ADM Scale/ControlNet Softness가 일반 생성과 블렌딩 워크플로우 모두에 실제로 적용된다.
- 로컬 자동화: Windows 작업 스케줄러 태스크 `ImageStudio-HourlyBackup`(매시간 Git 백업, scripts/backup/)과 `ImageStudio-DevLog`(매일 18시 개발일지 생성, scripts/devlog/)가 프로젝트와 별도로 로컬에서 동작하며, 각각 `.claude/skills/backup`, `.claude/skills/devlog` 스킬 문서로 관리 방법이 정리되어 있음.
- 배포/설치: 사내 100명 배포를 위해 `backend/server.py`가 미리 빌드된 프론트엔드(`dist/`)를 직접 서빙해 프론트+백엔드가 포트 5000 하나의 프로세스로 통합됨(2026-09-04). `scripts/installer/`에 NAS 공유폴더(기본 `\\192.168.166.7\Ax-lab\AI Image Studio`)에서 ComfyUI(체크포인트/LoRA 포함)·Ollama·앱 본체를 로컬(`C:\ImageStudio`)로 복사해 설치하는 `Install-ImageStudio.ps1`과 관리자 권한 승격용 `설치하기.bat`/`Elevate.ps1`, 실행용 `Start-ImageStudio.bat`이 있으며, NAS 준비 절차는 `NAS_배포_준비.md`에 정리됨.
