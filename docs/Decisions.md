- 로컬 자동 백업을 클라우드 루틴이 아닌 Windows 작업 스케줄러 기반으로 구현하기로 결정 (2026-09-02) — 클라우드 환경은 이 PC의 로컬 파일을 볼 수 없어 항상 "변경사항 없음"으로만 나오고 실제로는 백업이 전혀 되지 않고 있었기 때문.
- 이미지 블렌딩 기능은 Fooocus 원본처럼 "기본 이미지 vs 참조 이미지"라는 고정 역할 구분 대신, 슬롯(최대 4개)마다 타입과 설정을 독립적으로 갖는 구조로 재설계하기로 결정 (2026-09-02) — 실제 Fooocus UI에도 고정 역할 구분이 없고 슬롯이 스스로 역할(구조 유지용/스타일 참고용)을 정하는 방식이 원본 동작과 일치하기 때문.
- 갤러리 정리 기능은 참고자료/FAVORITES_FOLDER_FEATURE.md에서 검토했던 N:M(다대다) 폴더-이미지 조인 테이블 대신, "이미지 1개당 폴더 1개"로 단순화한 `image_generations.folder_id` 단일 컬럼 설계로 구현 결정 (2026-09-03). 폴더 삭제 시 이미지까지 삭제되지 않고 `folder_id`만 NULL로 되돌림.
